# OSSE Inc. — Escape from OSSE

야근 뒤 회사에 돌아온 주인공이 단서와 문서를 조사하며 탈출하는 포인트 앤 클릭 호러 게임입니다. 기존 사진 배경, 대사, 퍼즐, 박스키퍼·심대리·심콩 보스전과 엔딩을 유지했습니다.

## 실행

- 공개 게임: https://zaelee.github.io/ZZEE/20260915-ossescape/index.html
- 로컬: ZZEE 루트에서 `python -m http.server 4186` 후 `/20260915-ossescape/` 접속
- 새 빌드의 관리 위치는 이 디렉터리입니다. 원본 OSSEsecpae 폴더는 이전 버전으로 보존했습니다.

## 조작

- 클릭·터치: 조사, 대화, 선택지, 숫자 퍼즐
- WASD·방향키 또는 화면 클릭·드래그: 전투 회피
- E: 대화 진행·연타 / ESC 또는 상단 버튼: 메뉴
- 미니게임 ESC·일시정지 버튼: 일시정지·계속
- 휴대폰에서는 가로 화면을 권장합니다.

## 저장

진행은 같은 브라우저의 localStorage에 저장합니다. 이어하기는 수동·자동 저장 중 가장 최근의 유효한 기록을 불러옵니다. 대화, 퍼즐, 보스전과 엔딩 화면을 복원하며 미니게임은 해당 라운드 시작부터 재개합니다. 버전 10 저장은 현재 조우를 재시작하는 방식으로 복원합니다. 브라우저 데이터 삭제·다른 기기 간에는 기록이 공유되지 않습니다.

`?dev=1`에서 개발용 장면 이동 도구를 사용할 수 있습니다. 개발 분기로 이동한 세션은 새 게임·불러오기 전까지 저장하지 않습니다.

## 2026-09-15 수정

- 재시작·불러오기 때 남던 대화, 퀴즈, 퍼즐, 미니게임, 전투와 예약 콜백 초기화
- 저장에 현재 진행 상태 포함, 손상된 저장 거부 및 유효한 최신 슬롯 선택
- 재도전 체크포인트에서 출입카드·USB·쇠지렛대가 사라지던 Map 입력 형식 수정
- 메뉴·다른 탭에서 퀴즈와 전투 정지, 미니게임 ESC 일시정지 지원
- 미니게임 동시 피격 시 무적 시간 보장, 중복 애니메이션 루프 제거
- 전투 드래그, 터치용 메뉴·연타 버튼, 작은 화면의 잘리던 패널 개선
- 매 프레임 재생성되던 조사 버튼 유지 및 키보드 클릭 지원
- 진행 단계에 맞는 목표 안내, 깨진 퀘스트 문구와 이미지 참조 수정
- 데이터 로드 실패 시 재시도 안내, 저장소가 막혀도 설정 적용
- 개발 도구 기본 숨김, 사용하지 않는 BGM·언어 옵션 제거, 인트로 영상 지연 로드

## 검증

`node 20260915-ossescape/tests/regression.test.mjs` (ZZEE 루트)

저장소 전체 검사: `npm run check`
