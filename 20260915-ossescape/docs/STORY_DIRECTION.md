# AFTER HOURS: OSSE - Story Direction

## 핵심 톤

이 게임은 단순한 공포 방탈출이 아니라, `회사 생활 + 리미널 스페이스 + B급 코즈믹 호러`를 섞은 포인트 앤 클릭 어드벤처다.

플레이어가 느껴야 하는 감정 흐름:

1. "뭐야 이 회사ㅋㅋ"
2. "잠깐... 진짜 이상한데?"
3. "...이거 웃을 상황이 아니네."

공포의 중심은 괴물이 아니라 회사 자체다. 익숙한 회사 공간, 사내 시스템, 안내문, 방송, 문서가 조금씩 잘못되어 가는 느낌을 우선한다.

## 현재 구현 유지

아래 구현 흐름은 최대한 유지한다.

- 프롤로그
- 야간 회사 진입
- 경비실
- 출입카드 획득
- 1층 창고 탐험
- 창고 퍼즐
- 1층 사무실 비밀번호
- 1층 사무실 진입
- To Be Continued

이후 확장은 1층 사무실 뒤부터 자연스럽게 이어간다.

## OSSE 세계관

OSSE는 실제 회사처럼 보이는 기업이다.

- 브랜드 운영
- 유통
- 원료 수입
- Ingredient Trade

사건은 기존 제품 판매 때문이 아니라, 해외에서 연구용 원료를 수입하면서 시작된다.

## RB-13

RB-13은 `Red Bean Sample 13`의 코드명이다.

직원들은 처음에 "붉은콩 신품종인가 보다" 정도로 생각한다. 하지만 RB-13은 회사가 추구하던 효율, 생산성, 자동화, 증식을 지나치게 잘 수행하는 원료다.

중요 키워드:

- 증식
- 배양
- 혈액 반응
- 세포 활성
- 야간 개체수 변화

RB-13은 악의적인 괴물이라기보다, 너무 잘 증식하는 원료다. 이 점이 오히려 더 B급스럽고 기괴해야 한다.

## USB 이후 목표 갱신

초기 목표는 USB를 찾는 것이다.

USB를 찾은 뒤에는 안에 담긴 로그 때문에 2층 디자인실로 가야 한다.

예시:

```text
RECOVERY.LOG
DESIGN SERVER ERROR
2F ACCESS REQUIRED
```

목표는 항상 자연스럽게 갱신되어야 한다. 플레이어가 "왜 계속 회사 안에 있어야 하지?"라고 느끼지 않게, 문서와 시스템 로그가 다음 목적지를 알려준다.

## 회사가 살아있는 느낌

회사는 직접 공격하지 않는다. 대신 공간 자체가 살아있는 것처럼 행동한다.

연출 예시:

- 엘리베이터 층 표시가 `2F / 3F / 4F`에서 `2F / RB / 4F`로 변한다.
- 화이트보드 글씨가 아무도 없는데 조금씩 바뀐다.
- 의자, 상자, 프린터 위치가 확신하기 어려울 정도로 살짝 달라진다.
- 사원증 사진의 눈이 붉어지고, 마지막에는 심콩처럼 변한다.
- 출근 인증기는 새벽인데도 `출근 완료`를 표시하고, 후반에는 `퇴근 실패`를 표시한다.

변화는 노골적이면 안 된다. "내가 잘못 봤나?" 싶은 정도가 가장 좋다.

## 브랜드 변형

실제 회사 브랜드와 요소는 과하지 않게 변형한다.

예시:

- Laundry Surfing → Laundry Suffering
- Balance Route → Balance Root

한 글자만 바뀐 것처럼 보이게 하고, 플레이어가 처음에는 착각으로 넘기도록 만든다.

## 사내 방송

사내 방송은 처음에는 정상적인 회사 안내처럼 시작한다.

초반:

```text
좋은 아침입니다.
오늘도 좋은 하루 되세요.
```

하지만 현재 시간은 새벽이다.

후반:

```text
퇴근하십시오.
...
퇴근하지 마십시오.
...
죄송합니다.
```

방송은 점프스케어가 아니라 공간이 플레이어를 인식하는 듯한 불안감을 만드는 장치다.

## 복사기

복사기는 플레이어가 지나갈 때 혼자 종이를 출력한다.

초반:

```text
고생하셨습니다.
```

후반:

```text
왜 다시 왔나요?
보고할 직원이 없습니다.
```

## 사내 메신저

컴퓨터에서는 사내 메신저 로그를 볼 수 있다.

초반 예시:

```text
김대리: 붉은콩 누가 치웠어요?
박주임: ㅋㅋㅋㅋ
이과장: 다시 생김.
관리자: 먹지 마세요.
```

후반에는 참여자가 하나씩 사라지고, 관리자 또는 시스템만 남는다.

## 회의실

회의실에는 아무도 없지만 회의록은 계속 남아 있다.

예시:

```text
회의 안건: RB-13 처리 방안
결론: 다음 주 재논의
```

아무도 없는 공간인데 회의만 계속 진행된 것처럼 보여야 한다.

## 심콩

심콩은 악당이 아니라 퇴근하지 못한 직원이다.

예전에는 `심 대리`였고, RB-13에 가장 오래 노출되면서 심콩이 되었다.

말투:

- 커피...
- 발주...
- 회의...
- 퇴근...
- 입고...
- 증식...
- 배양...
- 입고 완료...

정답을 맞히면 잠깐 인간적인 기억을 되찾는다. 틀리면 `교육을 다시 받아.`라고 말하며 공격 패턴이 시작된다.

심콩에게는 공포와 안쓰러움이 동시에 있어야 한다.

## 문서 공포

문서는 초반에는 웃기고, 후반에는 건조하고 진지해진다.

초반:

```text
붉은콩을 발견해도 놀라지 마세요.
```

중반:

```text
붉은콩을 만지지 마십시오.
```

후반:

```text
만졌다면 보고하십시오.
```

마지막:

```text
보고할 직원이 없습니다.
```

게임은 진지한 바이오하자드가 아니다. 웃기면서도 찜찜하고, 익숙한 회사 공간이 점점 비현실적으로 변해가는 경험이 중심이다.

## 퍼즐과 인벤토리

아이템은 단순한 열쇠가 아니라 퍼즐을 해결하는 도구여야 한다.

좋은 아이템 설계:

- 한 장소에서 얻은 아이템을 다른 장소에서 다시 사용한다.
- 아이템끼리 조합해서 새로운 도구를 만든다.
- 문서, 환경, 사운드, 배치 변화를 함께 읽어야 한다.
- 회사에 있는 사물 자체가 퍼즐의 일부가 된다.

예시:

```text
드라이버 + 배터리 -> 손전등
손전등 + UV 필터 -> UV 손전등
고무장갑 + 붉은콩 -> 보관된 RB-13 샘플
열쇠 조각 A + 열쇠 조각 B -> 회의실 열쇠
```

퍼즐은 "왜 이 장소에서 해야 하는지"가 분명해야 한다.

- 경비실: CCTV와 출입기록
- 창고: 입고 리스트와 실제 박스 번호
- 창고 사무실: 화이트보드, 회사 연혁, 브랜드 포스터
- 1층 사무실: 메일, 메신저, 일정표
- 회의실: 프로젝터, 회의록, 배전반
- 탕비실: 정수기, 전자레인지, 냉장고
- 디자인실: UV 조명, 라이트박스, 프린터, 커팅매트
- 대표실: 금고, 액자, 트로피, 책장

최종 방향은 숫자 맞추기가 아니라 `회사라는 공간을 이해해야 풀리는 퍼즐`이다.
