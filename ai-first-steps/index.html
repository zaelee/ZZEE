04

컴퓨터는 켜 두고,
휴대폰으로 이어서 써요.

휴대폰에서 요청을 보내면, 연결된 컴퓨터가 실제 작업을 합니다.

PAIR ONCE · USE ANYWHERE

처음 한 번,
QR코드로 연결하세요.

아이폰은 App Store, 안드로이드는 Google Play에서 제작사가 OpenAI인 ChatGPT 앱을 설치하세요. 두 기기 모두 같은 계정과 워크스페이스로 로그인합니다.

휴대폰 연결 공식 안내 ↗
  1. 컴퓨터 앱의 Settings → Connections → Control this Mac or PC로 들어갑니다.
  2. Set up 또는 Add를 누르고 인증을 완료합니다. 나타난 QR코드를 휴대폰으로 읽습니다.
  3. 휴대폰 ChatGPT에서 연결을 마친 뒤 Codex 또는 Remote 메뉴를 엽니다.
  4. 연결한 컴퓨터와 기존 대화를 선택하고 메시지를 보냅니다.
매일 이 순서로컴퓨터 켜기→로그인·앱 실행→절전 상태 확인→휴대폰에서 대화 열기
컴퓨터 화면을 꺼도 되나요?

화면 꺼짐과 절전은 달라요. 컴퓨터가 잠들거나 앱이 종료되면 원격 연결을 쓸 수 없습니다. 연결 설정에 컴퓨터를 깨어 있게 유지하는 항목이 있으면 사용하세요. Windows 화면을 직접 클릭하는 Computer Use 작업은 잠금 해제된 화면이 필요하므로, 신뢰할 수 있는 장소에서 해당 화면을 작업용으로 확보하세요.

휴대폰에 컴퓨터가 보이지 않아요.

컴퓨터 앱이 켜져 있는지, 두 기기의 계정과 워크스페이스가 같은지, 원격 연결이 허용되어 있는지 확인하세요. Codex/Remote 메뉴가 없으면 양쪽 앱을 업데이트하고 기능 제공 여부를 확인합니다. 로그아웃 후에는 컴퓨터의 Remote Control을 다시 켜야 할 수 있어요.

휴대폰으로 컴퓨터 전원을 켤 수도 있나요?

이 안내는 먼저 컴퓨터를 켜 두고 사용하는 절차입니다. 꺼진 컴퓨터의 전원을 원격으로 켜는 별도 설정은 포함하지 않습니다. 일반 ChatGPT 질문은 컴퓨터 연결 없이 휴대폰 앱에서 할 수 있어요.

설정이나 설치 중 오류가 나면 어떻게 하나요?

오류 내용을 같은 Codex 대화에 보내고 “원인을 확인하고 이 설치 범위 안에서 해결해 줘”라고 요청하세요. 비밀번호·인증 키는 보내지 마세요. 설치됐다는 설명뿐 아니라 등록 상태와 실제 실행 검사 결과를 확인해야 합니다. 추가 화면 조작이 남았다면 그 단계까지 완료하세요.
