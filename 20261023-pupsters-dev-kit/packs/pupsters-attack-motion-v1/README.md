# 사고멍치 / PUPSTERS — 공격 모션

6종 강아지의 대기 → 준비 → 발동 → 반동 → 대기 복귀를 연결한 공격 애니메이션입니다. 캐릭터마다 서로 다른 4개 자세를 사용하며, 마지막에 대기 자세를 다시 재생합니다.

## 보기

압축을 푼 뒤 `index.html`을 브라우저로 열면 6종을 함께 볼 수 있습니다. 재생·일시정지·반복·효과 표시를 조절할 수 있으며 인터넷 연결이 필요하지 않습니다. 운영체제에서 동작 줄이기를 설정한 경우 처음에는 정지 상태로 열립니다.

`previews/`의 GIF와 무손실 WebP에는 캐릭터 동작만 들어 있습니다. 능력 효과는 `effects/`에 별도 PNG로 제공하고 HTML 미리보기에서 함께 재생합니다.

## 구성

- `frames/`: 6종 × 4개 자세 = 투명 PNG 24장, 각 1254 × 1254 px.
- `effects/`: 구슬, 공기탄, 냉기, 점착 거품, 정전기, 짖음 파동의 독립 PNG 6장.
- `previews/`: 반복 GIF 6개 + 무손실 애니메이션 WebP 6개.
- `animation-manifest.json`: 프레임 경로, 유지 시간, 능력 발동·종료 시점.
- `docs/`: 제작 프롬프트, 생성 기록, 인코딩·브라우저 검사 결과와 재실행 스크립트.

## 동작과 타이밍

시간은 대기부터 복귀까지 포함한 미리보기 1회 기준입니다. 실제 게임의 공격 속도나 피해 판정 수치는 아닙니다.

## 게임에 적용할 때

모든 캐릭터 프레임은 동일한 캔버스 크기입니다. 같은 피벗과 표시 크기로 교체하고, `animation-manifest.json`의 프레임 시간을 적용하면 됩니다. `ability_start`에서 해당 효과를 앞발·입·털 위치에 생성합니다. 효과 위치와 이동은 `preview.js`의 미리보기 구현을 참고할 수 있습니다.

현재 결과는 위에서 내려다보는 우하향 한 방향, 4개 자세의 프레임 애니메이션입니다. 다른 방향, 중간 동작 프레임, 게임 엔진 연결은 포함하지 않습니다. 기존 배경·UI·몹은 앞서 제공한 분리 에셋 패키지를 사용합니다.

## 제작과 확인

새 준비·회복 자세 12장은 내장 이미지 생성 도구로 제작했습니다. 기존 대기·발동 자세와 효과 원본은 그대로 사용했습니다. 이미지 프롬프트와 생성 기록은 `docs/motion-brief.json`, `docs/poses-a.json`, `docs/poses-b.json`에 보관했습니다.

PNG 원본의 크기나 그림을 바꾸지 않고 같은 프레임을 GIF·WebP로 인코딩했습니다. GIF의 팔레트와 투명도 표현에는 포맷 특성상 차이가 있으므로 원본 사용에는 PNG 또는 무손실 WebP를 권장합니다.

검사 결과:

- 24개 자세 PNG 디코딩·크기·투명도 확인.
- 견종별 4개 서로 다른 자세와 첫·마지막 대기 프레임 일치 확인.
- 12개 애니메이션의 5개 재생 구간·유지 시간·무한 반복 확인.
- 미리보기의 30개 이미지 로딩, 재생·정지·다시 재생, 효과 표시 확인.
- 데스크톱과 390 px 모바일 화면 확인, 가로 넘침 및 브라우저 오류 없음.
