# 사고멍치 / PUPSTERS — 캐릭터와 공격 v4

기존 견종별 색과 짧은 체형, 위에서 내려다보는 카메라를 유지하면서 표정과 몸에 붙은 능력의 흔적으로 개성을 구별한 대표 외형 6종입니다.

| 견종 | 성격 | 외형 포인트 |
| --- | --- | --- |
| 시바견 | 장난꾸러기 | 비대칭 눈썹과 웃음, 입에 문 작은 뼈다귀 |
| 불도그 | 고집쟁이 | 압축공기처럼 빵빵한 양 볼, 작은 아랫니, 말린 귀끝 |
| 허스키 | 시크하고 자신만만 | 귀끝·꼬리 끝 얼음, 볼의 서리, 차가운 눈빛 |
| 비글 | 호기심 많은 말썽꾸러기 | 둥근 눈, 입가의 거품, 귀끝의 분홍 흔적 |
| 푸들 | 예민하고 부산함 | 정전기로 곤두선 털끝, 레몬·보라 포인트, 긴장한 눈 |
| 보더콜리 | 눈치 빠른 대장 | 비대칭 귀, 또렷한 눈, 민트 목털과 꼬리 끝 |

압축을 푼 뒤 `index.html`을 열면 6종의 외형과 공격 방식을 보고 이전 모습과 비교할 수 있습니다. 시바 카드의 ‘뼈 뱉는 모션 보기’를 펼치면 새 공격 애니메이션이 재생됩니다. `attack-viewer.html`에서는 재생·정지와 시간 슬라이더로 동작을 살펴볼 수 있습니다.

## 공격 방식

| 캐릭터 | 무엇으로, 어떻게 |
| --- | --- |
| 시바견 | 작은 뼈를 입에 물고 있다가 입으로 퉤! 뱉기 |
| 불도그 | 볼에 모은 압축 공기를 입으로 뿜기 |
| 허스키 | 입에서 냉기 숨결 내뿜기 |
| 비글 | 끈적한 분홍 거품을 입으로 뱉기 |
| 푸들 | 털을 곤두세워 정전기 방출 |
| 보더콜리 | 짖는 파동으로 주변 아군 강화 — 지원형 |

상세 설명은 `ATTACKS.md`에도 정리했습니다.

- `characters/`: 수정된 대표 외형 6장, 각 1254 × 1254 px, 투명 PNG.
- `before/`: 비교용 이전 모습 6장.
- `manifest.json`: 캐릭터 이름·설명·파일 경로.
- `animations/shiba-bone/`: 새 시바의 물기·준비·뱉기·반동 자세 PNG 4장.
- `effects/FX01-bone.png`: 독립된 작은 뼈 투사체.
- `previews/D01-shiba-bone-spit.gif`, `.webp`: 뼈가 입에서 나오는 연결 애니메이션. 640 × 480 px, 1.48초 반복.
- `shiba-bone-animation.json`: 프레임 시간, 입 원점, 뼈 이동 시간표.
- `docs/designs-a.json`, `docs/designs-b.json`, `docs/designs-main.json`: 사용한 전체 프롬프트와 참조·생성 경로, 검토 기록.
- `docs/shiba-bone-main.json`, `docs/shiba-bone-poses.json`: 새 시바와 뼈, 공격 자세 제작 프롬프트와 기록.
- `docs/bone-validation.json`: 새 PNG·투명도·연결 애니메이션·6종 설명 화면 검사 결과.

제작 방식: 내장 image_gen으로 기존 캐릭터를 편집했습니다. 생성 PNG를 리사이즈하거나 다시 그리지 않고 원본 그대로 저장했습니다.

시바는 구슬과 앞발 투척을 폐기하고 작은 뼈를 입으로 뱉는 공격으로 변경했습니다. 모든 시바 자세에서 앞발은 바닥에 있으며, 뼈는 0.68초에 입에서 출발해 1.28초까지 움직입니다. 이후 다음 공격을 위해 뼈를 다시 문 대기 자세로 돌아갑니다.

이번 모션 갱신 대상은 시바입니다. 나머지 5종은 개성이 강화된 대표 외형과 공격 방식 설명을 포함하며, 새 외형의 공격 프레임은 아직 반영하지 않았습니다. 게임 엔진의 충돌·피해 판정과 수치 밸런스는 포함하지 않습니다.
