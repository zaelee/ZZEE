## 조립 기준

- 강아지 기본/능력 자세는 각각 독립 투명 PNG입니다. 한 방향의 정지 포즈이며 걷기·공격 연속 프레임은 포함하지 않습니다.
- 전경 이미지에는 투명 배경이 있습니다. E07 유리 몹 몸은 일부 반투명입니다.
- 도형·아이콘·문자는 분리했습니다. ui/labels.ko.json에 한국어 문구가 있으며 PNG에 글자를 구워 넣지 않았습니다.
- UI의 권장 9-slice 값은 ui/manifest.json을 참고하세요. 바의 채움 부분과 레일, 토글의 손잡이와 레일도 별개입니다.
- 냉기와 정전기 등 방향성 효과는 원본에서 왼쪽→오른쪽입니다. 게임에서 캐릭터의 입/앞발/몸 위치에 맞춰 회전·이동해 사용하세요.
- 원본 캔버스의 여백과 크기는 파일마다 다릅니다. 엔진에서 실제 도형 경계 기준으로 표시 크기를 맞추고 접지점과 효과 발생 위치를 설정해야 합니다.
- 거실 배경은 독립 배경 이미지 1장입니다. 바닥·길·가구가 포함되며 가구별 레이어 또는 타일셋은 아닙니다.
- 기존 승인된 말티즈·시바견·불도그 짧은 몸 기본 자세와 거실 배경을 재사용했습니다.
- 정지 아트 파츠 제작 범위이며 게임 동작·충돌 판정·애니메이션 구현은 포함하지 않습니다.

## 제작과 확인

캐릭터·몹·효과: built-in image_gen. 래스터 색보정·자동 누끼·코드 크롭을 적용하지 않았습니다.
UI: SVG 원본 제작 후 Sharp로 PNG 렌더링했습니다.

docs/image-prompts.json: 부모 작업의 생성 프롬프트와 참조/원본 경로.
docs/enemy-generation.json: 적 몬스터의 생성·수정 프롬프트와 확인 기록.
docs/boss-square-generation.json: 최종 보스 생성 프롬프트와 원본 경로.
docs/validation.json: 최종 PNG 디코딩·크기·알파 및 파일 검증 결과.

분리 파츠의 시각 확인과 파일 검증을 진행하며, 게임 엔진 내 애니메이션/배치 테스트는 이 작업 범위에 포함되지 않습니다.
