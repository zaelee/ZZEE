# 사고멍치 — 공격 동작과 효과 연결

강아지의 공격 자세와 능력 효과를 같은 시간표로 재생합니다. 앞발·입·털에서 효과가 시작되고, 강아지가 반동에서 회복하는 동안에도 이미 나온 효과는 계속 움직입니다.

압축을 푼 뒤 `index.html`을 브라우저로 열면 6종을 볼 수 있습니다. 슬라이더를 움직이면 원하는 순간을 정지해서 확인할 수 있습니다.

## 연결 방식

| 견종 | 연결된 동작 |
| --- | --- |
| 시바견 | 앞발이 펴지는 순간 구슬 출발 → 구슬 이동 중 앞발 복귀 |
| 불도그 | 입이 열리는 순간 작은 공기탄 발생 → 커지며 전진 → 반동 |
| 허스키 | 입에서 냉기 성장 → 내쉬는 동안 입에 연결 → 입을 닫으면 잔여 냉기 소멸 |
| 비글 | 입술 앞에서 거품 팽창 → 입에서 분리 → 이동 중 자세 복귀 |
| 푸들 | 털이 서는 순간 정전기 확장 → 잔광 → 털 복귀 |
| 보더콜리 | 짖는 순간 파동 발생 → 앞으로 퍼지는 동안 고개 복귀 |

## 파일

- `previews/`: 동작과 효과가 함께 들어 있는 투명 GIF 6개, 무손실 애니메이션 WebP 6개. 각 640 × 480 px.
- `frames/`: 기존 개별 캐릭터 자세 PNG 24장, 각 1254 × 1254 px.
- `effects/`: 기존 효과 PNG 6장.
- `animation-manifest.json`: 캐릭터 자세 시간표, 효과 시작·방출 종료·잔여 효과 종료, 발생 위치와 이동 설정.
- `data.js`, `preview.js`, `preview.css`: 오프라인 미리보기.
- `docs/validation.json`: 원본 일치, 연결 시점, 효과 지속, 반복 길이, UI 검사 결과.

미리보기 GIF·WebP는 기존 Canvas 애니메이션을 렌더링한 것입니다. 새 이미지를 생성하거나 기존 캐릭터 원본을 수정하지 않았습니다. GIF는 색상·투명도 표현이 제한되므로 고품질 투명 재생에는 WebP를 사용합니다.

## 게임 적용

동작과 효과를 하나의 공격으로 호출하되, 내부에서는 캐릭터 프레임과 효과를 별도 레이어로 유지할 수 있습니다. `effectTrack.startMs`는 발동 자세 시작과 같고, `emissionEndMs`는 새 효과를 내보내는 구간의 끝, `endMs`는 잔여 효과가 사라지는 시점입니다. 원점은 캐릭터 PNG의 좌상단 기준 정규화 좌표입니다.

구슬·거품 등의 실제 투사체는 게임에서 표적 위치와 거리, 충돌 판정에 따라 이동시킬 수 있습니다. 제공한 연결 GIF·WebP는 정해진 궤적을 가진 시각 미리보기이며 게임 엔진의 피해 판정은 포함하지 않습니다.

현재 방향은 우하향 한 방향입니다. 원래 분리 파일과 이전 버전은 보존했습니다.
