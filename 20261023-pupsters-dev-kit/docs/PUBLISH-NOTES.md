# 공개본 정리 내역

2026-10-23, 사용자가 이 대화에서 만든 결과물과 제작 스킬을 ZZEE의 오늘 날짜 폴더에 올리도록 요청한 범위입니다.

- 실제 결과물이 있는 21개 폴더와, ZIP에 남아 있던 중간 v4 스냅샷을 합쳐 22개 버전을 보존했습니다.
- 원래 output 파일은 수정하지 않고, 이 저장소의 복사본만 정리했습니다.
- 최신 7개 에셋 팩과 프로젝트 제작 스킬에 다운로드 ZIP을 만들었습니다. 이전 버전의 원본도 `packs/`에서 볼 수 있습니다.
- 사용자 홈·캐시의 절대 경로는 상대 경로나 생략 표시로 바꾸었습니다. 임시 이미지 생성 위치와 도구의 저장 안내 문구는 공개 기록에서 제거했습니다.
- Python 캐시, 로컬 브라우저에 결합된 검사 스크립트, 이미 별도로 공개된 원본 기획 HTML·제작 목록 중복본은 제외했습니다.
- 2D 이미지 프롬프트와 작업 결정은 보존했습니다. 이미지 생성 서비스 자체나 제삼자의 스킬·플러그인 원문은 복제하지 않았습니다.
- 최신 3D 5개 팩의 렌더 폰트를 PUPSTERS_FONT 환경 변수로 지정할 수 있게 했으며, 기본·사용자 지정·없는 폰트 오류 처리를 검사했습니다.
- 최신 3D 생성 코드와 JSON은 포함했습니다. Three.js를 사용하는 팩은 기존 저작권 고지 파일도 유지했습니다.
- 과거 validation 파일은 제작 당시 기록입니다. 공개 복사본의 새 체크섬은 다운로드 manifest와 각 최신 팩의 publication-manifest에서 확인합니다.

## 실제로 사용한 제작 흐름

2D는 기존 이미지와 프롬프트를 기준으로 이미지 생성 도구에서 수정했습니다. 3D는 파트·재질 JSON을 실제 메시와 Roblox 기본 Part로 내보내고, 같은 형상에서 미리보기를 렌더했습니다. 모션은 공통 프레임 데이터에서 GLB·Roblox 스크립트·웹 프리뷰·GIF를 만들었습니다.

스킬 정리는 이 프로젝트에 적용한 imagegen, Ponytail, Karpathy, Skill Creator의 역할과 재사용할 수 있는 제작 원칙을 담았습니다. 개인 설정이나 대화 기록을 통째로 백업한 것은 아닙니다.
