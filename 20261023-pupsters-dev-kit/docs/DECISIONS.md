# 결정 기록

## 현재 기준

- **최신 캐릭터 기준:** `pupsters-block-pack-v4`의 앉은 강아지 6종을 사용한다. 이전 2D·서 있는 3D·비율 탐색 버전은 역사 자료로 남긴다.
- **형태:** 큰 머리와 짧은 몸, 약간 통통하지만 비만하지 않은 비율, 뭉툭한 직육면체 중심 실루엣을 유지한다. 검은 점 눈, 네모 꼬리, 네모 뼈가 공통 언어다.
- **자세:** 기본 배치 자세는 앉은 자세다. 앞발은 나란히 바닥에 두고 공격 뒤 같은 자세로 돌아온다.
- **이름:** D01 시바멈, D02 불돔, D03 머스키, D04 미글, D05 무들, D06 모더콜리를 내부 캐릭터명으로 사용한다.

## 캐릭터별 식별 요소

| ID | 반드시 유지할 요소 | 능력 방향 |
| --- | --- | --- |
| D01 | 작은 흰 눈썹, 입에 문 네모 뼈 | 뼈를 입으로 뱉기 |
| D02 | 넓은 얼굴과 빵빵한 볼 | 압축 공기를 입으로 뿜기 |
| D03 | 사각 얼음 귀끝 | 냉기 숨결과 차가운 입김 |
| D04 | 긴 귀, 삼색 무늬, 파란 침 | 침방울 뱉기 |
| D05 | 기본형은 머리 중앙 지그재그 한 개 | 정전기 방출; 업그레이드는 주변에 여러 번개가 뜸 |
| D06 | 양쪽 귀, 찢어진 골판지 왕관 | 지원형 짖기 파동 |

총이나 기계식 무기는 쓰지 않는다. 공격은 각 강아지의 몸, 성격, 능력에서 나온다.

## 기술 결정

- 편집 가능한 scene/animation JSON을 기준 데이터로 두고 GLB, 웹 프리뷰, Roblox 모델을 같은 데이터에서 생성한다.
- Roblox에서는 기본 Part를 `Anchored=true`, `CanCollide=false`로 두고 스크립트가 위치·회전·크기·표시 상태를 재생한다.
- `Humanoid`, 스켈레탈 리그, 외부 `AnimationId` 의존성을 두지 않는다.
- 공격은 `Attack` BindableEvent, 적 동작은 `Motion` BindableEvent로 게임 로직과 시각 재생을 분리한다.
- 실제 피해, 이동, 스폰, 재화 같은 게임 규칙은 에셋 팩 안에 넣지 않는다.

## 맵 기준

- 전체 76 × 52 studs, 바닥 윗면 Y=0.
- 길 폭 6 studs, 길 윗면 Y=0.10, 중심 경로 길이 192 studs.
- 열린 S자 경로 W01~W06과 배치 칸 P01~P16을 사용한다.
- 배치 칸은 4.2 × 4.2 studs, 중앙 배치면 윗면 Y=0.26이다.
- 맵을 이동·회전한 뒤에는 Roblox의 현재 waypoint/slot CFrame을 사용한다. `layout.json` 좌표는 원래 배치 기준이다.

## 공개와 주장 범위

- `사고멍치`와 `Pupsters`는 작업명이며 상표 사용 가능성은 검증하지 않았다.
- 정적 구조·좌표·파일 간 일치와 생성된 프리뷰는 확인했다.
- Roblox Studio/Luau 실제 재생과 브라우저 WebGL 조작은 확인하지 않았다.
- 에셋 묶음을 “완성 게임”으로 부르지 않는다. 게임 통합의 미완료 항목은 [`HANDOFF.md`](HANDOFF.md)에 명시한다.
- 이 기록은 프로젝트 내부 결정과 산출물 관찰을 정리한 것이며 시장 조사나 법률 의견이 아니다.
