# 사고멍치 / PUPSTERS — 하나의 브랜드, 세 가지 운영

통합 정리일: 2026-10-28. 원 조사·콘텐츠 계획 기준일: **2026-10-27**. 이 문서는 기존 계획의 인수인계 요약이며 계정·게시·수익화·자동화가 새로 실행되었다는 뜻이 아니다.

## 1. 브랜드의 공통 중심

- 한국어 **사고멍치**, 영어 **PUPSTERS**, 발음 **펍스터즈**.
- 강아지의 장난과 습관이 개성으로 이어지는 브랜드. 같은 캐릭터가 게임에서는 능력, SNS에서는 웃음과 공감, 키즈에서는 작은 문제를 함께 해결하는 이야기로 등장한다.
- 공통 외형: 2D, 큰 머리·짧은 몸, 작은 코·점눈, 따뜻하고 분리된 색면, 일정한 역할별 선 두께.
- 시바의 흰 눈썹·작은 뼈, 머스키 귀끝 얼음, 미글 침, 무들 정수리 지그재그, 모더콜리 양쪽 귀와 고친 왕관 같은 식별 특징을 유지한다.
- 게임 문구 후보: **‘사고는 귀엽게, 수비는 똑똑하게.’** SNS·키즈의 모든 에피소드 끝에 억지로 넣을 필요는 없다.
- 최신 캐릭터 이름은 **불도그 / Hotdog**. 과거 자료의 불돔은 이전 표기다. 실제 원본을 고칠 때 내부 ID와 대본 등장인물 매핑을 보존한다.

## 2. 채널별 목적과 현재 상태

| 운영 축 | 대상·내용 | 먼저 만들 것 | 실제 현재 상태 |
| --- | --- | --- | --- |
| **Roblox 게임** | 강아지 조합·진화·타워 디펜스 플레이 | 이번 두 개편 MD를 최신 게임에 적용, QA와 밸런스 조정 | 기존 2D 작업 자료와 최신 개편 요청서 존재. 14종 최신 코드의 실행 상태는 이 전달 작업에서 미확인 |
| **일반 SNS 강아지툰** | 게임을 몰라도 이해되는 웃기거나 감동적인 일상·관계 이야기 | 짧은 4컷, 캐릭터의 행동으로 사건과 결말 전달 | 첫 재채기 편은 사용자 반려. 새 〈좋은 자리〉는 내부 검토 후 사용자 검토 대기, 게시 안 함 |
| **별도 키즈 YouTube** | 아이들과 가족이 보는 짧은 이야기·우정·생활 문제 해결 | 파일럿 대본·콘티 검수 후 그림·음성·영상 | 〈왕관보다 큰 집〉은 대본/콘티 단계. 완성 영상·수익화 결과 없음 |

세 운영 축은 캐릭터와 브랜드를 공유한다. 일반 SNS를 게임 광고 계정으로만 만들지 않고, 키즈를 일반 SNS 만화의 무조건적인 재업로드 채널로 취급하지 않는다.

## 3. 게임 운영과 다른 채널의 연결

- 우선 Roblox에서 플레이와 캐릭터 인지도를 쌓는 방향이다. 모바일/PC 확장은 가능성 검토 자료로 유지하며 출시가 확정된 것으로 말하지 않는다.
- 이번 최신 요구는 전투·UI·진행·아트의 실제 수정이다. 수정된 이름·외형·관계가 SNS와 키즈의 다음 제작에도 반영되도록 캐릭터 기준표를 갱신한다.
- 게임의 화상·동결·침·지원 능력을 SNS에서 매번 설명할 필요는 없다. 일상에서는 성격과 습관으로 자연스럽게 쓰고 키즈에서는 이해 가능한 행동으로 풀어낸다.
- 플랫폼 출시 비용·개발자 계정·상표 검토는 [기존 보고서](../20261028-pupsters-sns-handoff/brand/index.html) 및 [플랫폼 조사](../20261028-pupsters-sns-handoff/brand/research/platforms.md), [상표 조사](../20261028-pupsters-sns-handoff/brand/research/trademark.md)를 참고한다. 과거 가격·정책을 현재 확정값처럼 복사하지 말고 실제 가입·출시·출원 직전에 공식 조건을 재확인한다.

## 4. 일반 SNS — 4컷부터

- 사용자 의도: 게임 소개보다 **강아지툰**, 웃기거나 감동적인 이야기.
- 기존 편성 제안: 주 2편 만화, 여력이 있을 때 Instagram Reels 주 1편. 발행 약속이나 자동 게시 상태가 아니다.
- 기본 포맷: 세로 4:5 한 장의 2×2 네 컷, 인물 2~3명 이내, 컷당 행동 하나, 짧은 대사, 상황 → 계기 → 행동 → 결과.
- 강아지다운 본능과 관계가 사건을 만든다. 말장난 설명이나 마지막 교훈 대사만으로 결말을 대신하지 않는다.
- 매 편 먼저 대본 후보를 비교하고 콘티를 고른다. 캐릭터·소품·화자·동선을 정한 후 이미지를 만들고 최종 네 컷을 실제로 읽어본다.
- 최신 〈좋은 자리〉: 시바가 차지한 방석을 모더콜리의 ‘산책?’ 한마디로 뒤집는 이야기. **사용자 승인본은 아니다.** 피드백이 오면 이야기와 그림 중 해당 문제부터 수정한다.
- 첫 재채기 편은 [반려본 보관 위치](../20261028-pupsters-sns-handoff/archive/rejected-ep01/manifest.json)에 있다. 새 시안의 승인된 참고 예시로 사용하지 않는다.

### 참고 SNS 선정 기록

사용자가 초기 한국 레퍼런스의 인지도를 지적해 다시 조사했다. 처음 나온 목록을 그대로 최신 추천이라고 전달하지 않는다.

- [국내 강아지툰 재검토](../20261028-pupsters-sns-handoff/brand/research/korean-dogtoon-recheck.md): 강아지 행동·관계·연재 형식 참고.
- [국내 캐릭터 SNS/IP 재검토](../20261028-pupsters-sns-handoff/brand/research/korean-character-sns-recheck.md): 망그러진 곰, 무직타이거, 토잉×토슈의 공개 활동을 근거로 이야기·브랜드 확장·제작 리듬을 비교한 기록. 모두 강아지툰인 것은 아니다.
- 발표 당시 수치와 당시 확인일을 보존한다. 새 실시간 팔로워 수나 현재 성과로 바꾸어 말하지 않는다.
- `baoyu-comic`에서는 콘티·컷 역할·짧은 대사·일관성 검수 절차를 분석해 반영했다. 외부 스킬 전체 설치나 모델 재학습을 한 것은 아니다. 출처는 제작 규칙에 있다.

## 5. 키즈 YouTube — 별도 편성

- 기존 **5–8세 중심**은 연령 비교 후 제안한 방향이다. 사용자가 정확한 연령대를 최종 확정한 것으로 쓰지 않는다.
- 기존 제안: 16:9 본편 2–3분, 본편에서 독립적으로 이해되는 15–30초 세로 영상. 파일럿 검수 후 주 1편 목표, 제작 여력에 따라 격주 조정.
- 우정·친구 관계·작은 생활 문제를 캐릭터 행동으로 해결한다. 일반 SNS보다 상황 인과관계를 명확히 하고, 게임 전투 설명을 억지로 넣지 않는다.
- KIDS01 **〈왕관보다 큰 집〉**: 모더콜리가 자신의 왕관에 맞는 집에서 친구들이 함께 쉴 수 있는 집으로 생각을 바꾸는 이야기. 상태는 `script_review`다.
- 파일럿 그림·음성·영상은 미완성이다. 기존 문서에 자동화 요청문이 있다고 완성 영상이 자동 생산되는 것으로 설명하지 않는다.
- 수익화는 사용자 목표다. 조건 충족·심사·수익을 보장하지 않는다. 아동용 설정·공개·수익화 작업 시 최신 공식 정책을 다시 확인한다.

## 6. 무료 제작·자동화 인수인계 범위

- 기존 목표는 추가 비용을 억제하면서 Codex로 아이디어·대본·콘티·소재 목록·캡션·검수 기록을 쌓는 것이다. 모든 이미지/영상 도구가 무료·무제한이라는 뜻은 아니다.
- 제작 단계와 공개 단계를 분리한다: 아이디어 → 대본 → 콘티 → 원화/모션 → 내부 검수 → 사용자 검토 → 공개 승인 → 게시 결과 기록.
- 기존 예약 기록은 원래 PC/채팅에 남긴 스냅샷이다. 매주 월요일 오전 10시 한국시간 키즈 대본 적립, 검토 대기 4편이면 새 제작 보류라는 기록이 있다. **현재 예약 상태는 이번 전달 작업에서 조회하지 않았다.**
- 파일 복사나 ZIP 다운로드로 다른 PC의 예약·로그인·외부 계정이 이전되지 않는다. 이번 작업에서는 자동화를 새로 등록하거나 변경하지 않는다.
- [키즈 요청문 사본](../20261028-pupsters-sns-handoff/brand/automation-prompt.txt), [SNS 요청문 사본](../20261028-pupsters-sns-handoff/brand/sns-automation-prompt.txt)은 업무 참고 자료다. 사용자의 현재 요청 없이 실행 명령으로 취급하지 않는다.
