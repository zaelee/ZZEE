## 3. 해석 시 주의

- 이번 실행 범위는 위 수정 작업을 **다른 GPT에게 전달할 인수인계 자료로 묶고 GitHub에 푸시**하는 것이다. 현재 게임 구현을 완료했다는 뜻이 아니다.
- ‘난이도 별로’는 맵 이름 아래 난이도별 정보를 나누는 요구로 정리한다. 별 모양 아이콘을 반드시 사용하라는 뜻으로 단정하지 않는다. 오른쪽에는 쉬움/보통/어려움별 클리어 여부를 별도로 표시한다.
- ‘라운드’의 단위, 스킨 보너스 %, 해금 순서, 30포인트와 레벨 누적 관계는 아직 확정된 수치/규칙이 아니다. 구체 권장안을 확정 발언처럼 인용하지 않는다.
- 앞선 합체 결정: 서로 다른 5종 모두 최종 진화 후 실제 다섯 마리가 한 이동 추적대로 변환한다. 그 결과 방어 공백이 생기는 것이 의도이며 처치할수록 성장한다.
- 앞선 시바 결정: 주인공 격의 저렴한 시바 5마리를 최종 진화시켜 함께 쓰는 빌드와 3타 추가 피해/폭발. 추적대 합체와 별개다.
