### 골든과 모더콜리의 ‘직접 공격 없음’ 정의

- 피해 투사체, 음파 피해, 지속 피해, 반격 피해, 공격 명중 이벤트, 직접 처치 판정을 발생시키지 않는다.
- 아군 강화와 적 약화는 가능하다. 적의 체력을 직접 깎아서는 안 된다.
- 피해를 주지 않는다고 지원·탐지·디버프 갱신까지 멈추지 않도록 공격 루프와 지원 루프를 구분한다.
- 지원 오라를 그리는 효과를 피해 파장 로직에 잘못 연결하지 않는다.
- 이전 골든의 웨이브 보급 콜백과 예약된 사료 지급도 함께 제거한다.

## 3. 지원견과 은신·강철 대응

### 3.1 역할 배분 — 초기 설계안

| 지원견 | 아군 지원 | 적 대응 | 최종 강화 방향 |
| --- | --- | --- | --- |
| 골든 리트리버 | 범위 내 공격속도 증가 | 범위 내 **강철 취약점 파악·방어 감소** | 공속·범위 강화 또는 약점 분석 강화 |
| 모더콜리 | 범위 내 공격력 증가 | 범위 내 **은신 탐지 공유**. 중반 특전으로 약한 범위 감속 | 범위 확대 또는 공격력 지원 강화 |

초기 비교 수치: 기본 공격력/공속 오라 각각 **+10%**, 지원 강도 최종형 **+18%**. 골든의 강철 방어 수치 감소는 **15%**, 분석 특화형 **25%**. 모더콜리의 중반 감속은 **8%**, 강화 시 **12%** 정도부터 비교한다. **아직 확정 밸런스가 아니며 가격·반경·대상 수와 함께 조정한다.**

오라는 자기 자신과 피해를 주지 않는 다른 지원견의 공격 수치를 올리는 용도로 계산하지 않는다. 동일 종류 오라는 가장 강한 하나만 적용한다. 기본적으로 재적용은 지속 갱신이며 수치 누적이 아니다. 공격력 오라와 공속 오라는 서로 다른 종류이므로 함께 작동할 수 있다.

기존 골든 최대 2마리는 우선 유지하는 초기안이다. 두 마리로 범위를 넓힐 수 있으나 같은 아군에게 공속 보너스를 두 배로 주지 않는다. 실제 지원 효율을 보고 제한을 검토한다.

강철 약화도 적마다 동일 종류의 가장 강한 하나만 적용한다. 협동 플레이어가 다르더라도 같은 오라·약화가 무제한 중첩되지 않게 한다. 한 지원견이 사라졌을 때 다른 유효한 지원견의 효과로 다시 평가한다. 두 번째 골든의 주 용도는 다른 길목의 범위 확보이며 사료 보상은 어느 개체에서도 발생하지 않는다.

### 3.2 범위 판정

- **버프:** 지원견의 범위 안에 있는 아군에게 적용.
- **탐지·분석·감속:** 지원견의 범위 안에 있는 적에게 적용.
- 모더콜리 범위 안에서 드러난 은신 적은 공격수가 자기 공격 사거리 안에 두고 있다면 공격할 수 있다. 공격수까지 모더콜리 오라 안에 있을 필요는 없다.
- 적이 범위를 벗어나면 탐지 공유와 범위 디버프를 해제한다. 지원견 판매·합체·제거 시에도 즉시 해제한다.
- 초기 판정안: 타깃 선정·발사 시 탐지가 필요하고, 이미 발사한 투사체는 범위를 벗어난 적에게 명중 가능. 강철 방어 감소는 명중 시점의 상태를 사용한다. 프로젝트의 기존 판정과 다르면 하나로 통일하고 설명·테스트를 맞춘다.
- 은신과 강철을 함께 가진 적은 두 속성을 따로 판정한다. 강철 분석만으로 은신까지 탐지하지 않는다.

### 3.3 골든이 다시 필수 견종이 되지 않게 할 것

강철의 ‘파악’은 **약점을 찾아 표시하고 방어를 낮추는 분석**으로 구체화하는 것을 권장한다. 강철은 기본적으로 보이는 적이다. 골든이 없으면 모든 공격이 무효가 되는 유일한 해제 열쇠로 만들지 않는다.

- 강철은 높은 물리 방어를 가지되 화상, 적절한 공격 속성, 초중반 방어 관통 특전 등 대체 공략을 제공한다.
- 시바의 최종 관통도 대체 경로지만, 강철이 초반에 등장한다면 최종 강화만을 대체 경로로 계산하면 안 된다.
- ‘방어 수치 15% 감소’와 ‘피해 감소율 15%p 감소’를 혼동하지 않는다. 기존 방어 공식에 맞는 한 방식으로 통일한다. 방어가 없는 적에게 음수 방어를 만들지 않는다.
- 은신도 기존 시바 2단계 자체 탐지 등 접근 가능한 대안을 남긴다. 그 자체 탐지를 아군 전체에 공유하지 않는다.
- 첫 은신·강철 웨이브 이전에 실제로 구매·강화할 수 있는 대안이 각각 있는지 QA한다.

## 4. 조합 포함 여부와 초·중반 강화

‘아무 5종이나 추적대 재료로 쓸 수 있다’는 이유만으로 전 견종이 충분히 조합에 참여한다고 평가하지 않는다. 합체 전에도 그 견종을 고를 이유가 있어야 한다.

| 강아지 | 현재 조합에서의 위치 | 초·중반 역할·보완 방향 |
| --- | --- | --- |
| 시바멈 | 사냥 예고 소비자, 시바 오총사 핵심 | 가장 저렴한 기본 공격수. 시작 견종 기준점 |
| 불도그 | 과열 폭파 핵심 | 최종 특전 전에도 광역 화상으로 물량 처리 |
| 머스키 | 꽁꽁 놀이 핵심 | 기본 감속으로 안정적인 방어 시간 확보 |
| 미글 | 동결·전도 반응의 물 공급 | 적은 투자로 길목 점착 유지 |
| 무들 | 과열 폭파·전도 반응 핵심 | 3마리 연쇄만으로 초반 물량에 기여 |
| 모더콜리 | 사냥 지휘의 선택 지원자 | 탐지 공유·공격력 지원. 직접 피해 삭제 후 초반 효용 재평가 |
| 닥스훈트 | 사냥 예고 공급자 | 초반 정예를 확실히 줄이는 단일 공격 |
| 잭 러셀 | 사냥 예고 확장 후보 | 긴 줄의 적을 왕복 타격. 회수 속도는 최종 특전 전에도 개선 가능 |
| 코기 | 과열·전도 확장 후보 | 다방향·짧은 길목의 초반 물량 처리. 기본 공격 간격·가격 조정 후보 |
| 셰퍼드 | 과열 폭파 확장 후보 | 첫 포탑 가동을 빠르게, 초반 정비 공백을 짧게. 기본 가동/정비 효율 검토 |
| 골든 | 특정 최종 반응의 필수 멤버 아님 | 공격견 몇 마리가 모인 초·중반부터 공속 지원·강철 약화 효율 체감 |
| 래브라도 | 동결·전도의 다른 물 공급자 | 범위 피해와 제한적인 밀어내기로 침 웅덩이와 차별화 |
| 세인트버나드 | 특정 최종 반응의 핵심에서 빠짐 | 기본 보호량을 낮은 투자로 확보. 최종 특전 없이도 실수 복구에 가치 |
| 치와와 | 얼음 깨기 확장 후보 | 초반 고속 적을 끊는 짧은 기절. 값비싼 최종 반응 없이도 역할 확보 |

우선 보완 대상은 **골든·세인트버나드**, 그다음은 조합 확장에만 쓰이는 **잭 러셀·코기·셰퍼드·치와와와 개편 후 모더콜리**다. 지원견의 ‘초반에 강함’은 직접 DPS가 아니라 아군 증가 피해, 누수 감소, 탐지 가능 시간, 투자 회수로 평가한다. 지원견 하나만 놓고 첫 웨이브를 막게 만들 필요는 없다.

| 놀이 초반 | 한 바퀴 놀이 | 코기의 기본 공격 간격이나 초기 사거리 개선 |

| 무리 초반 | 응원 연습 | 골든·모더콜리의 지원 범위·접근 비용 개선 |
| 무리 초·중반 | 든든한 친구 | 세인트버나드의 기본 보호 예산·가격 효율 개선. 라운드마다 무제한 회복 아님 |

노드 이름과 개수는 구현 후보다. 실제 트리에 같은 역할이 있으면 재사용하고 불필요한 노드를 늘리지 않는다. 기본 성능까지 약하게 만든 뒤 필수 특전으로 정상화하는 방식은 피한다.

## 5. 30포인트 특전 구조

| 계열 | 정체성 | 최종 또는 주요 노드 |
| --- | --- | --- |
| 사냥 | 상태·표식을 큰 피해로 전환 | 과열 폭파 / 사냥 예고 |
| 놀이 | 원소·투사체·지형의 상호작용 | 꽁꽁 놀이 / 물장구 찌릿 |
| 무리 | 같은 견종의 집결 또는 여러 견종의 합체 | 깊은 최종: 시바 오총사 / 접근성 있는 보조 갈림길: 냄새 추적대 |

### 비용·선행조건 원칙

- 기존 배분 예산은 30포인트. 최신 레벨당 1포인트 획득 요구와의 관계는 UI·진행 문서의 결정 필요 항목을 따른다. 권장안은 누적 획득과 전투 적용 최대 30을 분리하는 것이며, 아직 사용자가 이 해석을 확정한 것은 아니다.
- 초기 비용 예시는 **주력 최종 도달 20포인트 + 추적대 접근 전체 6포인트 + 초·중반 선택 4포인트**다. 현재 구현된 비용이라는 뜻은 아니다.
- ‘추적대 6포인트’는 무리의 필수 선행 노드를 포함한 **총 접근 비용**이다. 다른 계열을 완주한 뒤 접근할 수 없는 깊이에 숨기지 않는다.
- 추적대는 특전 포인트 부담은 작아도 최종 진화 5종을 실제 소모하는 큰 전투 투자다.
- 각 계열의 최종 효과 후보 중 몇 개를 동시 선택할 수 있는지는 실제 트리와 함께 정한다. 초기 비교안은 한 계열의 최종 반응 하나를 선택하는 구조다.
- 기존 HUNT·PLAY·PACK 성장/저장 규칙을 확인하고, 이 문서만 보고 한 판짜리 임시 특전으로 바꾸지 않는다.
- 모든 조합의 조건, 미충족 멤버, 특전 비용, 합체 대상은 UI에서 볼 수 있어야 한다.

## 6. 사냥·놀이 최종 특전

### H1. 과열 폭파 — 사냥 최종

**기본 출발: 불도그 + 무들.**

- 감전된 적에게 화상이 들어가거나 화상 적에게 감전이 들어가면 폭발한다.
- 반응 중심 적과 주변 적에게 추가 폭발 피해. 화상은 유지하고 반응용 감전 표식을 소비하는 초기안을 사용한다.
- 동일 대상의 반응 쿨타임 초기값은 3초. 공격 순서만 바꿔 쿨타임을 우회하지 못하게 한다.
- 반응 피해는 원본 직접 공격과 구분한 고유 계수로 계산한다. 파생 폭발이 다시 감전/화상을 만들어 자기 자신을 재발동하지 않는다.
- 코기 확장 후보: 코기 구슬에 최근 맞은 적의 폭발 범위 확대.
- 셰퍼드 확장 후보: 포탑 가동 초기에 감전 적을 우선 공격하고 점화성 보조탄을 제한적으로 공급. 이 성질은 최종 특전에서만 얻는다.
- 보스에게 폭발 피해는 적용 가능하되 보스 면역을 무시하는 기절·밀어내기를 덧붙이지 않는다.

### H2. 사냥 예고 — 사냥 최종

**기본 출발: 시바멈 + 추가 견종 닥스훈트.**

- 느린 닥스훈트의 직접 공격이 적에게 사냥 표식을 남긴다.
- 시바멈의 뼈가 표식 적을 맞히면 표식을 한 번 소비하고 추격 피해를 준다.
- 추격 피해는 표식을 만든 닥스훈트의 기준 공격력과 고유 계수로 정한다. 시바가 빨라졌다고 같은 표식을 여러 번 소비하지 않는다.
- 초기 표식 수명 4초, 적마다 해당 플레이어의 활성 표식 하나. 갱신/교체 규칙을 명확히 한다.
- 잭 러셀 확장 후보: 돌아오는 원반도 표식을 소비할 수 있음. 같은 표식의 중복 소비는 금지.
- 모더콜리 확장 후보: 지휘로 표식 적의 우선순위를 잠시 높임. **모더콜리 자신의 피해 공격으로 표식을 만들거나 터뜨리지 않음.**

### P1. 꽁꽁 놀이 — 놀이 최종

**출발 A: 머스키 + 미글. 출발 B: 머스키 + 추가 견종 래브라도.**

- 동상 + 젖음이 겹치면 완전동결. 미글과 래브라도는 같은 젖음 공급자로 판정한다.
- 초기 비교값: 일반 적 **1.2초 이동 정지**, 동결 중 받는 피해 **+20%**.
- 감속을 중첩해 사실상 영구 정지를 만드는 대신 별도 동결 상태로 처리한다.
- 동결 종료 후 재동결 저항을 둔다. 초기 3초부터 비교하며, 기절을 섞어 제어 저항을 우회하는 경우도 테스트한다.
- 보스·동결 면역 적에게 정지 효과를 강제로 적용하지 않는다. 대체 취약 효과를 줄지는 적별 규칙으로 명시하고 시험한다.
- 래브라도는 웅덩이 밖 적에게 즉시 젖음을 공급해 범위를 연결한다.
- 닥스훈트는 동결 중 강한 한 발을 넣는 선택 지원자다.
- 치와와 확장 후보: 남은 동결 시간을 포기하고 짖음으로 얼음을 깨 추가 피해. 자동으로 동결과 기절을 연속 적용하지 않는다.

### P2. 물장구 찌릿 — 놀이 최종

**기본 출발: 무들 + 미글, 또는 무들 + 래브라도.**

- 젖은 적을 거쳐가는 번개의 다음 대상 탐색 거리가 늘어난다.
- 초기 비교값: 조건 충족 시 최대 연결 대상 **3 → 4마리**.
- 같은 연쇄에서 이미 맞은 적에게 되돌아가 무한 순환하지 않는다.
- 미글은 한 길목에 젖음을 유지하고, 래브라도는 떨어진 적에게 젖음을 전달한다.
- 코기 확장 후보: 구슬에 맞은 적을 다음 연결 대상으로 우선 선택.

### 공통 반응 규칙

- 특전이 잠겨 있으면 해당 합동 반응도 잠겨 있어야 한다. 상태 자체의 기본 효과와 최종 반응을 분리한다.
- 같은 감속 종류·같은 취약 종류는 가장 강한 하나를 우선하는 초기안을 사용한다. 여러 약화 수치를 무심코 모두 곱하지 않는다.
- 한 원본 공격에서 같은 원소 반응을 여러 번 발동시키지 않는다. 복수 반응이 가능한 공격은 선택한 특전과 명시적인 우선순위로 일관되게 처리한다.
- 표식·젖음·동상·감전·화상에는 소유자, 출처, 만료 시간, 소비 여부를 추적할 수 있어야 한다.
- 파생 피해는 원소 반응·사냥 표식·시바 3타를 재귀적으로 생성하지 않는 것이 기본이다.

## 7. 무리 최종 특전 — 시바 오총사

**같은 시바 5마리를 끝까지 키워 쓰는 주인공 주력 빌드다.**

- 조건: 본인 시바 5마리 모두 최종 진화 + 해당 무리 최종 특전.
- 다섯 개체를 유지한다. 냄새 추적대처럼 한 개체로 합치지 않는다.
- 조합에 참여한 5마리가 같은 적에게 남기는 뼈 표식을 공유한다.
- 1회 명중: 표식 1개. 2회 명중: 2개. **3회 명중: 표식 소비, 강화 타격과 작은 물리 뼈 파편 폭발**.
- 기준은 발사 수가 아닌 실제 직접 명중 수다. 동시 명중에서도 3회마다 정확히 한 번 처리한다.
- 초기 비교값: 세 번째 직접 명중에 해당 시바 공격력의 **100% 추가 피해**, 주변에는 **40% 파편 피해**. 이는 조정 가능한 초기안이다.
- 세 번째 원본 뼈의 방어 무시 여부는 실제 발사 시바의 최종 강화와 일치시킨다. 주변 파편까지 무조건 방어 무시로 확대할지는 따로 명시하고 시험한다.
- 파편은 새로운 표식을 만들지 않는다. 화염 폭발과 다른 물리 파편 효과로 표현한다.
- 다른 적의 표식끼리 합치지 않는다. 표식 수명·전투 종료 정리·참여 시바 제거 시 처리 규칙을 명시한다.
- 초기 판정안: 표식은 대상별 4초 유지하며 새 직접 명중으로 갱신한다. 공격수가 표적을 바꿔도 이전 적의 표식은 만료 전까지 남는다. 최초 구현은 3/6/9타마다 발동하도록 하고, 공격속도가 높아 과도하면 피해 계수부터 조정한다. 별도 쿨타임을 넣는 경우 무시된 명중·표식 처리와 UI를 명시해 3타 규칙이 조용히 달라지지 않게 한다.
- 6번째 시바가 추가되더라도 임의로 전부 참여하지 않도록 참여 5마리와 최대 활성 무리 수를 정의한다. 초기안은 플레이어당 오총사 한 묶음이다.
- 연사는 표식을 빠르게 쌓고, 방어 무시는 강화 타격의 질을 높인다. 어느 한 강화가 모든 상황에서 필수인지 QA한다.
- 다섯 시바를 최종 진화시키는 총비용을 혼합 빌드와 비교한다. 저렴한 주인공의 장점이 끝까지 살아 있어야 한다.

## 8. 무리 보조 특전 — 냄새 추적대

### 8.1 최신 확정 구조

1. **본인의 서로 다른 견종 5종**을 고른다.
2. 선택한 다섯 개체가 **모두 최종 진화 완료** 상태여야 한다.
3. 냄새 추적대 특전을 해금한다.
4. 합체 버튼을 누르면 **기존 5마리를 실제로 소모하고 이동 추적대 1개체를 생성**한다.
5. 원래 다섯 자리가 비고, 원래 공격·버프·탐지·보호 효과가 사라진다. 그 결과 적이 뚫릴 수 있는 것이 의도된 전략적 대가다.
6. 추적대는 그 전투 동안 유지되고, 직접 처치할수록 공격력이 증가한다.

**기존 본체를 남겨 둔 지원군 복제, 6초 출동 후 복귀, 최종 진화하지 않은 5종으로 해금하는 안은 폐기한다.**

### 8.2 행동·슬롯·효과 승계

- 외형은 다섯 견종이 한 대형으로 움직이는 무리, 논리적 전투 유닛은 하나다. 같은 적의 죽음을 다섯 개체가 중복 집계하지 않는다.
- 추격 구역 또는 경로를 지정하고 빠른 적을 우선 추적한다. 유효한 빠른 적이 없으면 출구에 가까운 적을 노리는 초기안을 사용한다.
- 적이 없거나 경계를 벗어나면 정해진 대기 위치로 돌아온다. 경로 밖 정체·순간이동·무한 표적 전환을 시험한다.
- 공통 물기·합동 공격을 사용하며 기존 다섯 마리의 모든 공격을 그대로 복제하지 않는다.
- 지원견을 재료로 썼다면 그 오라·탐지·사료·보호량을 무료로 계속 유지하지 않는다. 세인트버나드의 남은 보호 예산도 그대로 복제하지 않는다.
- 초기안: 플레이어당 활성·보유 추적대 최대 1개. 이미 보유 중이면 추가 합체를 거절한다. 기존 다섯 배치 위치는 재배치 가능하고 추적대는 이동 유닛 1개로 수를 계산한다. 실제 게임의 슬롯/상한에 맞춰 명시한다.
- 재합체·판매·특전 초기화로 처치 수나 사용한 보호량을 복제할 수 없게 한다. 판매 시 다섯 재료를 자동 복원하지 않는다. 환급 정책은 실제 경제 규칙과 함께 정한다.
- 합체 뒤 새로 배치한 골든·모더콜리의 범위 지원은 정상적으로 받을 수 있다. 범위를 벗어나면 해제한다.
- 2인 협동에서 상대의 강아지를 몰래 재료로 쓰거나 양쪽이 같은 재료를 동시에 합체하지 못하게 한다.
- 합체 전 UI에서 사라지는 배치 위치와 주요 지원 효과를 보여준다. 합체 직후 빈 길목을 플레이어가 알아볼 수 있어야 한다.
- 합체 시 원본 다섯 마리의 남은 투사체·지속 피해·예약 공격을 취소하는 초기안을 사용한다. 진행 중 공격을 남기는 기존 규칙을 선택한다면 원본 출처로 끝까지 추적하고 추적대 처치 성장으로 귀속하지 않는다. 원본 오라·탐지·보호는 즉시 종료한다.

### 8.3 처치당 공격력 성장 — 권장 초기안

사용자가 원한 방향은 **몹을 한 마리 잡을 때마다 공격력이 조금씩 오른다**는 것이다. 우선 공격력만 성장시킨다. 공격속도·범위·이동속도·사료 수입까지 처치당 동시에 올리지 않는다.

- `K`: 해당 추적대가 이번 전투에서 직접 처치한 보상 대상 적의 수.
- `A0`: 합체 시 확정한 추적대의 기초 공격력. 이후 오라·취약·임시 강화와 독립적으로 보관.
- 모든 증가율은 **A0에 대한 가산 증가율**이다. 현재 공격력에 매번 1.001을 곱하는 복리가 아니다.
- 권장 초기안: 처음 500처치는 **1처치당 +0.10%**, 501~1500처치는 **+0.05%**, 이후는 **+0.02%**.
- 이후에도 증가하므로 처치 성장의 재미는 유지하되 무한 도전의 급격한 증폭을 줄인다. UI는 누적 처치 수·총 증가율·현재 한 처치당 증가율을 보여준다.

```text
G(K) = 0.001 × min(K, 500)
     + 0.0005 × min(max(K - 500, 0), 1000)
     + 0.0002 × max(K - 1500, 0)

성장 반영 공격력 = A0 × (1 + G(K))
```

| 직접 처치 수 | 고정 가산 0.1%안의 증가량 | 권장 감쇠안의 증가량 | 권장안 공격력 배수 |
| ---: | ---: | ---: | ---: |
| 0 | +0% | +0% | 1.00배 |
| 100 | +10% | +10% | 1.10배 |
| 300 | +30% | +30% | 1.30배 |
| 500 | +50% | +50% | 1.50배 |
| 1,000 | +100% | +75% | 1.75배 |
| 1,500 | +150% | +100% | 2.00배 |
| 3,000 | +300% | +130% | 2.30배 |
| 5,000 | +500% | +170% | 2.70배 |
| 10,000 | +1,000% | +270% | 3.70배 |
| 100,000 | +10,000% | +2,070% | 21.70배 |

**이 감쇠식에도 절대 상한은 없다.** 100,000처치 스트레스 테스트까지 포함하고 적의 체력 성장·실제 최장 전투와 비교한다. 무한전에서 지배적이면 세 번째 구간의 증가율을 더 낮추거나 완만한 성장식/상한을 비교 제안한다. 사용자가 원한 지속 성장의 방향을 임의로 웨이브마다 초기화하지 않는다. 상한 유무와 최종 채택식을 QA 보고서에 명시한다.

참고: 매 처치마다 현재 공격력에 1.001을 곱하면 1,000처치에서 약 **2.7169배**, 5,000처치에서는 약 **148.0428배**가 된다. 이 복리 방식은 사용하지 않는다.

### 8.4 0.1%가 실제로 적절한지 판단하는 법

처치 수를 보기 전에는 ‘0.1%면 밸런스가 맞는다’고 확정할 수 없다. 합체가 가능한 시점 이후 실제로 얼마나 많은 적을 추적대가 잡을 수 있는지가 중요하다.

| 한 처치당 고정 가산 증가율 | 100처치 | 300처치 | 500처치 | 1,000처치 |
| ---: | ---: | ---: | ---: | ---: |
| 0.05% | +5% | +15% | +25% | +50% |
| 0.075% | +7.5% | +22.5% | +37.5% | +75% |
| 0.10% | +10% | +30% | +50% | +100% |
| 0.15% | +15% | +45% | +75% | +150% |

위 네 후보와 권장 감쇠안을 같은 조건에서 비교한다. 예를 들어 합체 직후 직접 DPS가 기존 다섯 공격수 합의 60%라고 가정하고 타격 시간·저항이 같다면, 고정 0.1%안은 약 **667처치**, 감쇠안은 약 **834처치** 후에야 그 직접 DPS 합에 도달한다. 이는 가정한 산술 예시이며 실제로 5마리 지원 효과와 배치 범위까지 회복한다는 뜻은 아니다.

따라서 초기 성능을 임의로 절반 이하로 정한 뒤 처치 성장만으로 복구시키지 않는다. 공격 가능 시간, 추격으로 줄인 누수, 합체 재료 가격, 사라진 지원 효과까지 비교한다. 일반 스토리에서 남은 직접 처치 기회가 100~200뿐이라면 성장률 또는 기초 성능·합체 시점을 다시 조정해야 한다.

### 8.5 성장 집계 규칙

- 우선 일반 적·정예·보스 모두 보상 대상 적 한 개체의 직접 처치당 1회 집계한다. 별도의 경험치 가중치와 공격력 처치 수를 섞지 않는다.
- 초기안은 아군 처치·어시스트로 공격력 증가 없음. 협동 막타 경쟁이 문제면 별도 어시스트 규칙을 제안하고 성장률을 다시 검증한다.
- 이미 죽은 적, 같은 사망 이벤트 재전송, 훈련용·환영·무한 소환 악용 개체는 중복 성장시키지 않는다.
- 분열·소환 적은 실제 보상 대상 판정과 일치시킨다. 무한 증식으로 무제한 성장이 가능한지 별도 시험한다.
- 전투가 끝나면 K와 성장 보너스를 초기화한다. 같은 전투의 저장/불러오기를 지원하면 중복 증가 없이 복원한다.
- 골든·모더콜리 오라가 들어오고 나갈 때 A0나 K를 다시 계산하지 않는다. 버프가 기초 공격력에 영구 저장되면 안 된다.
- 피해 계산 순서를 정하고 테스트한다. 예: `A0 × 성장 배수 × 아군/특전 공격 보정 × 스킬 계수 × 적 취약 보정 × 방어 보정`. 같은 종류 보정의 중첩 규칙은 따로 적용한다.
- UI 반올림 때문에 1처치 증가가 보이지 않더라도 내부 수치는 정밀하게 누적한다.

### 8.6 남겨둘 선택과 미확정 후보

- 일찍 합체: 빈 진형을 감수하고 쉬운 몹부터 먹여 후반 성능 확보.
- 늦게 합체: 기존 다섯 마리로 버티지만 성장 시간이 줄어듦.
- 합체 안 함: 넓은 공격 범위와 지원 효과 유지.

**대장 선택으로 성질 하나를 계승하는 방식은 검토 후보이며 확정 기능이 아니다.** 먼저 가장 저렴한 5종만 합체 재료로 고르는 문제가 실제로 있는지 확인한다. 필요하면 경제·재료 투자량·계승 하나 중 최소한의 방법으로 해결하고, 원본 스킬 다섯 개를 전부 승계하지 않는다.

## 9. 골든 보급 삭제와 전투 경제

- 골든의 라운드별 추가 사료 지급, 사료 강화 선택지, 비스킷 공격, 관련 툴팁·도감·보상 이벤트를 제거하거나 교체한다.
- 전투 사료의 기본 획득은 모든 플레이어가 접근하는 처치·웨이브 완료 등 공통 구조를 기준으로 검증한다.
- 기존 경제가 골든의 추가 수입을 전제로 했다면 공통 보상·업그레이드 가격·웨이브 구성을 조정한다. 골든을 다른 필수 경제 견종으로 이름만 바꾸어 옮기지 않는다.
- 합체 요구인 ‘다섯 종 최종 진화’가 중반 또는 의도한 성장 구간에서 실제로 가능한지 확인한다.
- 미래 먹이 보급 요소는 별도 검토다. 이번 수정에 랜덤 보급 상자·유료 수입·새 화폐를 자동으로 추가하지 않는다.
- 골든을 빼도 클리어 가능한 경제, 골든을 넣으면 특정 전투 조건에서 도움이 되는 지원 효율을 목표로 한다.

## 10. 최종 QA와 밸런스 조정 요청

**기획 검토로 끝내지 말고, 최종 QA 담당자로서 실제 결과를 확인하고 문제를 수정해 주세요.** 코드에 수치만 넣고 ‘밸런스 완료’라고 보고하지 마세요. 기존 테스트·검사 체계를 활용하고 필요한 전투 테스트를 추가하세요.

### 10.1 먼저 수집할 실제 값

- 14종의 단계별 가격, 총 최종 진화 비용, 공격력, 공격 간격, 범위, 타격 수, 가동률, 제어 시간.
- 골든·모더콜리의 반경별 평균 지원 대상 수와 실제 아군 증가 피해.
- 강철 방어 공식, 속성 저항, 은신 타깃 판정, 보스 제어 면역.
- 모드별 웨이브 몹 수, 보상, 속도, 체력, 분열·소환 개체 수.

### 10.3 비교 플레이 구성

같은 총 투자 사료, 같은 사용 특전 포인트, 같은 웨이브 조건을 맞춰 비교한다. 추가 비용이 드는 조합을 무료 성능 증가처럼 비교하지 않는다.

1. 시바 중심 기본 편성 / 시바 오총사 / 혼합 물리 편성.
2. 과열 폭파 / 동결 / 전도 / 표식 사냥.
3. 각 주요 편성에 지원견 없음 / 골든만 / 모더콜리만 / 둘 다.
4. 골든·세인트버나드·잭 러셀·코기·셰퍼드·치와와를 최종 특전 없이 쓰는 초·중반 편성.
5. 같은 다섯 멤버를 계속 유지 / 이른 합체 / 중간 합체 / 늦은 합체.
6. 추적대 고정 가산 0.05%, 0.075%, 0.10%, 0.15%와 권장 감쇠안.
7. 보급 삭제 전 경제 의존도를 확인한 뒤, 보급 없이도 가능한 공통 보상·가격 조합.

최소한 짧은 스토리·긴 스토리·무한전, 솔로·2인 협동, 빠른 적·물량·정예·은신·강철·보스 구간을 포함한다. 무작위성이 있으면 동일 시드를 사용하고 주요 비교는 여러 시드로 반복한다. 우선 5시드를 시작점으로 삼고 경계 결과만 확대한다.

기록할 값: 총 투자, 클리어/실패, 누수 피해, 처치 시간, 남은 사료, 견종별 직접/지원 기여, 제어 가동률, 합체 시점·후속 처치 수, 추적대 투자 회수 시점, 프레임/서버 비용.

### 10.4 밸런스 판단 기준

- 모든 견종을 같은 DPS로 만들지 않는다. 각 견종이 유리한 초기 상황이나 지원 상황이 최소 하나는 있어야 한다.
- 골든 또는 모더콜리가 모든 모드·모든 편성에서 항상 최선이거나 없으면 진행 불가능하면 대응 경로와 지원 효율을 수정한다.
- 경제 보급 삭제 때문에 모든 견종의 최종 진화 시점이 의도보다 뒤로 밀리지 않았는지 확인한다.
- 추적대는 이른 합체가 무조건 정답이거나 항상 손해인 상태를 피한다. 성장시킬 기회와 빈 진형 위험이 모두 실제로 관측되어야 한다.
- 시바 오총사는 초반 접근성과 후반 주력 가능성을 가지되 모든 방어·물량·보스 상황에서 다른 조합을 압도하지 않게 한다.
- 최대 성장 추적대만 시험하지 않는다. 합체 직후와 100~300처치 구간에서 플레이가 성립하는지도 확인한다.
- 초기 수치가 맞지 않으면 직접 수정하고 같은 조건에서 재검사한다. 변경 전후 표를 남긴다.
- 실행하지 못한 항목은 미검증으로 구분한다. 가상 시뮬레이션과 실제 플레이 검증을 섞어 쓰지 않는다.

- 캐릭터·배경·공격 효과·UI를 분리한다. 게임 화면 한 장을 그린 것으로 부품 제작을 완료하지 않는다.

- 매 처치마다 현재 공격력에 1.001을 곱하는 복리 성장은 사용하지 않는다.
- 브랜드·SNS 보고서의 옛 6종 설명을 최신 전투 사양으로 취급하지 않는다.
