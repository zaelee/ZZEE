사고멍치 / PUPSTERS 게임을 다음 문서와 최신 사용자 요청에 맞춰 실제로 수정해 줘.

먼저 `UI_PROGRESSION_REWORK_REQUEST.md`, `PUPSTERS_GAMEPLAY_REWORK_REQUEST.md`, `USER_REQUESTS_20261028.md`를 읽고 현재 프로젝트에서 대응하는 화면·공격·특전·저장·보상 로직을 찾아줘. `THREE_CHANNEL_OPERATIONS.md`와 옆 폴더 `20261028-pupsters-sns-handoff`의 브랜드·SNS·키즈 자료도 함께 인수인계받아. 예전 6종 시제품만 보고 최신 14종·빌리지 구현까지 확인했다고 하지 마.

이번 우선순위는 **실제 게임의 UI·게임플레이·진행 시스템과 아트 수정**이야. SNS와 키즈 기획은 브랜드를 일관되게 이어가기 위한 배경 자료야. 이 요청만으로 SNS 게시, 계정 생성, 영상 자동화 예약, 유료 서비스 구매를 하지는 마.

필수 작업은 다음과 같아.

1. 가로 전투 화면·소환/배치·맵 선택·빌리지·티어·스킨·특전·가방·커뮤니티·프로필·설정 UI를 수정해. 아이폰 16 가로 화면의 왼쪽 안전 영역과 실제 Roblox 기본 UI, 오른쪽 설정 버튼을 기준으로 사용 가능한 공간을 맞춰. 배경을 덮는 설정 오버레이는 전체 게임 뷰포트를 덮어야 해.
2. 풍선 타워 디펜스의 배치·선택·업그레이드 UI를 실제로 확인하고 정보 배치 원리를 참고해. 큰 설치 선택창에 역할·가격·사거리·공격 주기·효과·진화·조합 정보를 읽기 쉽게 넣고, 맵 경로와 배치 자리를 계속 볼 수 있게 해. 참고한 화면과 차용한 원리를 기록하되 해당 게임의 그림을 복제하지 마.
3. 전투 MD의 14종과 특전·반응·합체를 적용해. 골든·모더콜리는 직접 공격 없이 지원·탐지·디버프를 담당하고, 골든의 사료 보급은 없애. 추적대는 서로 다른 최종 진화 5종을 실제 소모해 한 유닛이 되며 직접 처치로 성장해.
4. 레벨당 특전 1포인트, 5레벨마다 추가 견종 해금, 사용량 기반 조각, 스킨 티켓 보너스, 멍코인과 스킨 상점을 구현해. 문서의 확정 요구와 권장 수치를 구분하고, 30포인트 제한과 레벨 보상, 보상의 ‘라운드’ 단위처럼 결과를 바꾸는 미결정 규칙은 근거와 권장안을 제시해. 기존 저장·보유 자산을 보존해.
5. 새 견종 중 그라데이션 등 스타일이 다른 것만 기존 2D의 분리된 색면으로 교정해. 모든 견종·스킨의 진화별 원화와 공격 모션을 만들고, 지원견은 지원 동작으로 만들며 스킨창과 실제 게임에 연결해. 앞으로 추가할 캐릭터도 같은 제작 요건을 통과해야 해. 공격할 때 작아지는 문제는 PNG 캔버스가 아니라 실제 몸 크기와 발 기준점으로 맞춘 뒤 게임 화면에서 비교해.
6. 조합 트리 6종의 스킨 콘셉트 보드와 골든·모더콜리 지원형 개편 시안을 실제 이미지로 제작해. 장착 가능한 최종 에셋과 콘셉트 이미지는 구분해.
7. 마지막에는 **QA 담당자라고 생각하고 기능·저장·반응형 UI·보상 중복·접근성·성능·밸런스를 확인해**. 같은 비용·특전·웨이브로 빌드를 비교하고, 문제가 있으면 직접 조정하고 재검사해. 실제 플레이와 수식/시뮬레이션 결과는 구분하고, 하지 못한 검사는 미검증으로 남겨.

아이디어 목록이나 첫 시안으로 끝내지 말고 실제 수정 파일, 검증 가능한 실행본, 전후 화면, 아트 산출물, 변경 수치와 검사 결과까지 제출해 줘. 아직 최신 프로젝트가 없다면 이 점을 명확히 알리고 필요한 프로젝트 위치를 요청하되, 독립적으로 할 수 있는 명세·콘셉트 정리는 먼저 진행해.
