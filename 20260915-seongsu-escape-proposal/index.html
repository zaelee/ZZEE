마지막 고객은 의뢰인 자신입니다.

아버지가 마지막으로 만들고 싶었던 것은 아들이 자기 발로 세상에 나갈 때 신을 구두였습니다. 초반의 생일, 19세라는 나이, 첫걸음이라는 주문 이유가 다시 연결됩니다.

구두 안쪽에는 원안의 문구 FOR MY FIRST STEP, ‘나의 첫걸음을 위해’가 새겨져 있습니다.

어머니는 아버지가 어린 시절 자신의 아버지를 잃고 가난하게 자랐다고 전합니다. 그는 사랑하는 방법을 제대로 배우지 못한 사람이었습니다. 이해할 여지는 남기되, 가족의 상처를 지우거나 용서를 요구하지 않습니다.

“네가 어디로 가든,
네 발에 잘 맞는 길을 걷기를.
이것이 내가 너에게 남기는 마지막 유산이다.”
— 제공 원안의 마지막 편지에서

엔딩 구현 제안 플레이어가 처음부터 지닌 봉인 봉투를 서울숲에서 엽니다. NFC로 구두 이미지와 마지막 편지를 공개합니다. 실제 구두를 키트에 넣는 구성은 아직 정하지 않았으며, 첫 버전은 종이 소품과 웹 화면으로 제안합니다.

반전은 ‘나이 19’만으로 맞히게 하지 않습니다. 장남의 생일·치수·이름을 연결하는 증거를 추가 설계해야 합니다.

03 / Technology with a role

신기한 기능마다
이야기 속 역할을 줍니다.

첫 버전에는 아래 6가지를 권합니다. NFC로 만지고, 위치를 확인하고, 카메라로 기록을 발견합니다. 기능이 실패해도 이어 갈 방법을 함께 만듭니다.

01핵심 · 낮은 구현 난도

카드를 대면 열리는 기록

NFC · 가까이 대서 웹 주소 열기

종이 주문서에 휴대전화를 대면 사진, 음성, 새 증거가 열립니다. 실물과 웹이 하나로 이어지는 가장 중요한 장치입니다.

쓰는 장면 시작 카드 → 고객 기록 → 이웃의 증언 → 작업 기록 → 마지막 봉투

작동 방식 · 안 될 때의 대안

태그에는 짧은 HTTPS 주소를 넣고, 휴대전화의 기본 읽기 기능으로 엽니다. 알림을 누르는 과정이 있을 수 있습니다.

아이폰 XS 이후의 기본 태그 읽기와 NFC 지원 안드로이드 기기를 대상으로 실물 테스트합니다. 웹페이지가 직접 태그를 읽는 Web NFC는 별개이며 아이폰 공통 방식으로 쓰지 않습니다.

대안: 모든 카드에 QR과 짧은 코드를 함께 인쇄합니다. 태그 주소만으로 구매 권한이나 현장 방문을 증명하지는 못합니다.

Apple · 기본 태그 읽기 / Chrome · Web NFC

02핵심 · 중간 구현 난도

그곳에 가야 열리는 장면

위치 확인 · GPS 등으로 도착 확인

목적지에서 ‘도착했어요’를 누르면 근처에 왔는지 확인합니다. 눈앞의 풍경을 읽는 짧은 문제를 함께 풀어 장면을 엽니다.

쓰는 장면 첫 골목 도착 확인과 서울숲의 마지막 장면. 모든 장소마다 반복하지는 않습니다.

작동 방식 · 안 될 때의 대안

브라우저의 위치 확인 기능은 HTTPS와 사용자 허용이 필요합니다. 건물 주변에서는 위치가 흔들릴 수 있어, 80–120m를 초기 시험 범위로 두고 현장에서 조정합니다.

화면을 열고 버튼을 눌렀을 때 확인합니다. 웹을 닫은 상태의 지속 추적이나 정확한 방문 증명은 전제하지 않습니다.

대안: 위치 확인이 실패하면 현장의 관찰 문제와 도움말로 진행합니다. 이것은 부정 이용을 완전히 막는 장치가 아닙니다.

MDN · 웹 위치 확인 기능

03대표 연출 · 중간~높음

주문서 위에 뜨는 기억

AR · 카메라 화면에 장면 겹치기

키트의 주문서 그림을 비추면 오래된 도면이나 작업 장면이 겹쳐 나타납니다. 처음 한 번은 ‘종이 안에 숨은 기록을 찾는’ 놀라움을 줍니다.

쓰는 장면 성수연방 주변의 안전한 정지 지점에서 고객 주문서 한 장을 인식합니다.

작동 방식 · 안 될 때의 대안

MindAR 같은 도구로 미리 등록한 인쇄 그림을 카메라가 찾게 만듭니다. 아무 건물이나 찍으면 자동으로 알아보는 기능은 아닙니다. 카메라 위에 겹치는 것은 VR보다 AR에 해당합니다.

HTTPS와 카메라 허용이 필요합니다. 아이폰·갤럭시 실제 기기에서 종이 반사, 야외 밝기, 구형 기기 속도를 검증해야 합니다.

대안: ‘기록 직접 보기’를 누르면 같은 단서를 이미지나 짧은 영상으로 보여 줍니다. AR 성공 여부에 정답을 가두지 않습니다.

MindAR · 이미지 인식 AR / MDN · 카메라 권한

04핵심 · 중간 구현 난도

가족에게서 도착한 말

웹 속 연락처 · 메시지 · 음성

연락처를 복원하면 가족의 메시지가 차례로 나타납니다. 짧은 음성과 자막으로 이웃과 어머니의 증언을 들려줍니다.

쓰는 장면 출발 전 가족 대화, 대림창고 주변의 이웃 기록, 서울숲으로 가는 길의 어머니 증언

작동 방식 · 안 될 때의 대안

게임 안에 만드는 대화 화면입니다. 실제 번호로 전화하거나 메시지를 보내지 않아도 연출할 수 있습니다. 핵심 대사는 미리 확정합니다.

음성은 사용자가 재생을 눌렀을 때 시작합니다. 웹을 닫으면 실제 전화처럼 벨이 울리는 기능은 아닙니다.

대안: 모든 음성에 같은 내용의 자막을 제공합니다. 소리를 끄거나 외국인 여행객이 번역된 글을 읽어도 단서가 같습니다.

MDN · 웹 소리 자동 재생의 제약

05감각 연출 · 낮은~중간

빛을 비추면 보이는 흔적

가상 손전등 · 화면 속 숨은 글씨

손가락으로 빛을 옮기거나 기록의 표면을 문지르면 아래쪽 글씨가 드러납니다. 오래된 작업 기록을 직접 살펴보는 느낌을 만듭니다.

쓰는 장면 수제화 테마공원 부근에서 치수와 작업 메모를 확인하는 장면

작동 방식 · 안 될 때의 대안

Canvas라는 웹의 그림 도구로, 화면 위 이미지 일부를 가리거나 드러냅니다. 실제 UV 잉크를 카메라로 읽는 기술은 아닙니다.

한 손 조작, 작은 화면, 손가락에 가려지는 글씨를 확인합니다. 색 차이만으로 정답을 구분하지 않습니다.

대안: ‘기록 전체 보기’로 같은 단서를 엽니다. 정교한 손 움직임이 어려워도 진행할 수 있게 합니다.

MDN · 이미지 겹치기와 지우기

06핵심 · 중간 구현 난도

흩어진 단서가 맞물리기

증거 보관함 · 단계 해금 · 이어 하기

생일, 고객 기록, 치수가 하나의 주문서로 모입니다. 대화를 다시 읽고, 단계별 힌트를 쓰고, 잠시 쉬었다 이어 할 수 있게 만듭니다.

쓰는 장면 전 구간의 진행 저장과 마지막 주문서 완성. 같은 결말에 도달하되 읽는 순서는 일부 선택합니다.

작동 방식 · 안 될 때의 대안

기능 제안입니다. 판매용 게임은 키트의 시작 코드와 팀별 진행을 서버에서 확인하도록 설계합니다. 서버는 웹 뒤에서 사용권·정답·저장을 처리하는 곳입니다.

이 NFC 카드가 어떤 기록을 여는지와, 지금 그 기록을 볼 수 있는 단계를 나누어 관리합니다. 중요한 정답을 공개 HTML에 그대로 넣지 않습니다.

대안: 재접속 코드를 제공하고 저장 실패를 알려 줍니다. 현재 제안서를 올린 GitHub Pages는 정적 페이지 호스팅이며, 이 판매용 서버가 구현된 상태는 아닙니다.
