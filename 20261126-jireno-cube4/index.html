제레노 CUBE4를 켜면
크롬캐스트가 뜨게 하려면

Projectivy Launcher는 제레노 빔 본체에만 설치합니다. 크롬캐스트는 HDMI에 꽂아 두세요. 빔을 켰을 때 처음 나오는 제레노 홈에서, 제레노 리모컨으로 시작합니다.

본체에 설치자동 시작 설정안 될 때

1. 제레노 본체에 앱 설치

이미 USB에 APK가 있다면

  1. USB 메모리를 제레노 본체 뒤의 직사각형 USB 단자에 꽂으세요.
  2. 제레노 홈에서 File Browser를 열어 USB 메모리를 선택하세요. 목록 이름은 메모리나 펌웨어에 따라 다를 수 있습니다.
  3. ProjectivyLauncher-4.74-c101-xda-release.apk를 선택하고 설치 → 열기를 누르세요. ‘이 출처의 앱 설치’ 안내가 뜨면 파일을 연 앱에만 허용한 뒤 돌아와 다시 설치하세요. 설치 후 해당 허용을 꺼도 됩니다.

앱스토어나 노트북에서 시작한다면

본체 스토어에서 Projectivy Launcher를 검색해 개발자가 Spocky인 앱을 설치하세요. 검색되지 않으면 맥북이나 윈도우에서 아래 APK를 받아 압축을 풀지 않고 USB에 복사한 뒤 위 순서를 따르세요.

2. HDMI를 먼저 열어 보고, 부팅 입력으로 지정

  1. Projectivy 안에서 입력(Inputs) 목록을 열고 HDMI를 누르세요. CUBE4 영상에는 HDMI2로 나옵니다. 번호보다 실제 크롬캐스트 홈이 뜨는 항목이 중요합니다.
  2. 제레노 리모컨의 홈 버튼을 눌러 Projectivy로 돌아가세요. Projectivy 설정 → 전원(Power) → 부팅 시 자동 시작(Autostart on boot)에서 방금 성공한 HDMI를 고릅니다. 구버전에는 Power control → Startup to로 표시될 수 있습니다.
  3. 크롬캐스트는 전원을 공급한 채 둡니다. 제레노의 전원 메뉴에서 종료한 다음, 빔 전원만 다시 켜세요. 휴대폰 전송이나 외부입력 버튼을 누르지 않고 크롬캐스트 홈이 뜨면 성공입니다.

Projectivy는 안드로이드가 올라온 뒤 입력을 엽니다. 제레노 로고나 홈이 잠깐 보일 수 있습니다. 개발자가 제공하는 기능이지만 CUBE4에서 완전 종료 후 자동 전환까지 재현한 공개 사례는 확인되지 않았습니다.

3. 막힌 화면을 고르세요

스토어에 앱이 없고, USB도 목록에 안 보여요

제레노 홈의 File Browser에서 확인하세요. 노트북에서는 읽히는데 본체 목록에 USB 자체가 없다면, 이 빔에서 읽힌 적 있는 다른 USB에 APK 한 개를 복사해 보세요. 제조사 안내에서 NTFS·FAT32 지원표를 확인할 수 없어 기존 USB를 포맷할 근거는 없습니다.

본체에 웹브라우저와 다운로드 기능이 있다면 이 안내를 그 브라우저로 열어 공식 APK 받기를 누른 뒤 다운로드 목록에서 파일을 여는 방법도 있습니다. 본체 브라우저에서 설치 파일 열기를 지원할 때 쓸 수 있습니다.

제조사의 USB APK 설치 안내

USB에 APK는 보이는데 ‘설치할 수 없음’이 떠요

출처 허용 메시지라면 File Browser에 대한 설치 허용을 확인하세요. 파일을 해석할 수 없음이라면 ZIP이나 다운로드 중인 파일을 골랐는지 확인하고 공식 APK를 다시 받으세요. 이 배포본의 크기는 11,488,308바이트입니다.

기존 앱과 서명이 충돌한다는 메시지가 뜨면 기존 버전을 설치했던 스토어에서 먼저 업데이트하세요. 삭제 후 재설치는 저장된 런처 설정을 잃을 수 있습니다.

스토어와 USB가 모두 안 돼요. 노트북으로 설치할 수 있나요?

제레노 본체가 디버깅 연결을 허용할 때는 가능합니다. 노트북에 Android Platform-Tools를 받아 압축을 풀고, 공식 APK도 그 폴더에 넣으세요. 본체의 개발자 옵션에 네트워크 디버깅과 접속 주소가 표시된다면 같은 Wi-Fi에서 그 주소로 연결하고, 승인 창이 뜨면 본체에서 승인하세요.

아래는 윈도우 PowerShell 예시입니다. Platform-Tools 폴더에서 실행하고 본체IP:포트와 본체ID를 실제 값으로 바꾸세요. 맥 터미널에서는 .\adb.exe 대신 ./adb를 씁니다.

.\adb.exe connect 본체IP:포트
.\adb.exe devices -l

목록에서 제레노 본체가 device로 표시될 때만 해당 줄의 맨 앞 ID를 사용하세요. 외장 크롬캐스트도 안드로이드 기기이므로 대상을 확인하세요.

.\adb.exe -s 본체ID install -r "ProjectivyLauncher-4.74-c101-xda-release.apk"

Success가 뜨면 본체에서 앱을 열고 자동 시작 설정으로 돌아가세요. CUBE4에는 안드로이드 9 탑재 사례가 있어 같은 Wi-Fi에 연결하는 것만으로 ADB를 사용할 수 있다고 가정할 수 없습니다. 본체의 무선 디버깅 메뉴나 PC용 USB 디버깅 단자는 공개 자료에서 확인되지 않았습니다.

공식 Platform-ToolsGoogle의 ADB 연결·설치 안내

앱은 설치됐는데 HDMI가 없거나 눌러도 열리지 않아요

먼저 제레노 원래 홈의 외부입력에서 크롬캐스트가 보이는지 확인하세요. 거기서도 ‘신호 없음’이면 크롬캐스트 전원과 HDMI 연결부터 확인하세요.

원래 홈에서는 보인다면 Projectivy의 입력 목록이 숨겨졌는지 확인하세요. 그래도 항목이 없거나 다른 화면이 열린다면 이 펌웨어가 외부 앱에 HDMI를 제공하는지 미확인입니다. 기본 홈을 바꾸기 전에 아래 대안을 보세요.

앱에서 HDMI는 열리지만, 껐다 켜면 제레노 홈에 남아요

부팅 시 자동 시작을 다시 열어 선택한 HDMI가 저장됐는지 먼저 보세요. 크롬캐스트를 켜 둔 상태에서 Projectivy에 자동 시작 지연 옵션이 보이면 지연을 조금 늘리고 완전 종료 후 다시 시험하세요.

재부팅 때 본체가 기본 홈 앱을 묻는 경우에만 Projectivy를 선택해 항상으로 시험할 수 있습니다. 원래 홈으로 돌리려면 본체 설정의 기본 홈 앱에서 기존 런처를 다시 고르세요. 기본 홈 선택 메뉴는 펌웨어마다 다를 수 있습니다.

완전 종료 후에는 되는데 짧게 껐다 켤 때만 실패한다면 대기 복귀 동작을 확인하세요. 개발자 변경 내역에서는 대기 복귀 자동 실행을 별도 기능으로 설명하며, 이 기능에는 Projectivy 접근성 서비스가 필요합니다. 먼저 완전 부팅 결과를 확인한 뒤 결정하세요.

자동 시작 지연·대기 복귀 변경 내역

그래도 자동 전환이 안 되면

CUBE4에서 시작 입력을 HDMI로 영구 저장하는 제조사 메뉴나 검증된 ADB 설정값은 찾지 못했습니다. 이 경우에는 빔 전원 한 번만으로 끝나는 방법을 확인하지 못한 상태입니다.

휴대폰으로 재생을 시작하는 경우에는 외장 크롬캐스트로 영상을 전송해 보세요. 양쪽에서 HDMI-CEC가 작동하면 그 시점에 입력이 바뀔 수 있습니다.

크롬캐스트 음성 리모컨이 있다면 크롬캐스트의 설정 → 리모컨 및 액세서리 → 리모컨 버튼 설정에서 전원·입력 버튼을 각각 시험하세요. 제레노가 반응하면 리모컨 하나로 조작할 수 있습니다.
