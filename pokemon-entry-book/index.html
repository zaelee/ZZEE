1세대부터 최신작까지, 가능한 한 타입이 겹치지 않는 6마리와 입수 순서·운용법·추천 육성 정보를 한곳에 정리했다. 직접 지정한 엔트리에 타입 충돌이 있으면 경고와 대체안을 함께 표시한다.

엔트리 선정 우선순위

1. 보유 타입 무중복한 팀 안에서 같은 타입을 두 번 사용하지 않는다.
2. 전설은 최대 1마리스타팅과 메인 전설의 타입도 겹치지 않게 한다.
3. 팀 내 기술명 무중복같은 게임의 서로 다른 포켓몬에게 같은 기술을 배치하지 않는다.
4. 자속기 우선자속기 → 공격 타입 다양성 → 약점 카운터 순서로 기술을 고른다.
5. 역할과 세대 개성물리·특수·스피드·탱커를 섞고, 해당 작품 신규 포켓몬과 복합 타입을 우선한다.

확정안과 임시 추천안

사용자가 직접 지정한 엔트리는 확정안으로 표시했다. 나머지 1~7세대 팀은 우선 조합을 보는 임시 추천안이며 각 시리즈에 교체 예시를 함께 표시했다.

1~3세대에서는 타입에 따라 물리·특수가 고정된다. 레벨업 기술은 Lv., 기술머신·가르침은 레벨 무관, 교배기는 부화 시로 표시한다.
