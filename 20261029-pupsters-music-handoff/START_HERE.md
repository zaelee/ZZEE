# 사고멍치 / PUPSTERS 음악 적용 인수인계

2026-10-29 · 게임 적용 준비 자료. **게임에 이미 연결됐거나 Roblox에 업로드된 자료가 아니다.**

## 다음 작업자에게 전달할 요청

이 폴더의 `README.md`, `MUSIC_USAGE.md`, `ROBLOX_IMPORT_AND_QA.md`, `data/music-usage.json`, `data/roblox-upload-register.csv`를 읽고, 사고멍치 최신 게임 프로젝트에 음악을 연결해 줘.

이 저장소는 제작 자료를 모은 정적 사이트다. 최신 게임의 `src/client/Audio.luau`, `src/shared/GameModes.luau`, `src/shared/Preferences.luau`는 이번 인수인계 과정에서 직접 확인하지 못했다. 이 경로들은 이전 제작팩에 적힌 탐색 단서이며 현재 구조와 같다고 단정하지 마. 실제 프로젝트에서 화면 전환, 맵·모드·웨이브·보스 상태, 설정 저장과 오디오 재생 코드를 먼저 찾아 줘. 이전 [게임·UI 인수인계](https://github.com/zaelee/ZZEE/blob/gh-pages/20261028-pupsters-game-ui-handoff/START_HERE.md)와 [SNS·브랜드 인수인계](https://github.com/zaelee/ZZEE/blob/gh-pages/20261028-pupsters-sns-handoff/HANDOFF.md)도 함께 읽어.

1. `audio/bgm/`의 34개와 `audio/jingles/`의 16개는 **연결용 임시 후보**다. 각 사용처의 A안 후보 1에서 만든 편집 초안이므로, 실제 청취 후 적합한 후보를 선택해. `audio/promo/`의 6개는 홍보 영상용 15·30·60초 컷이며 게임 BGM 목록에 자동으로 넣지 마.
2. 먼저 P0의 M01–M16과 해당 징글부터 적용해. 맵 식별자는 기존 기획 기준 `room`, `garden`, `shop`, `duo_yard`, `endless_room`이지만 실제 프로젝트에서 재확인해. M17–M20은 짧은 모달을 열 때마다 새 음악을 틀지 말고, 장시간 머무는 독립 화면에서만 선택적으로 사용해. 미래 후보 F01–F10과 미구현 연출은 콘텐츠가 실제로 존재할 때만 켜.
3. Roblox에는 직접 음원을 업로드하고 실제 자산 ID와 소유자·경험 권한을 확인한 뒤 `data/roblox-upload-register.csv`의 빈 항목을 채워. GitHub 파일 URL은 Roblox 자산 ID가 아니다. 임의의 숫자 ID를 만들거나 업로드·승인·권한 부여가 끝났다고 추정하지 마.
4. 플레이어당 BGM 하나를 기본으로 유지해. 전환 중에만 짧게 두 트랙을 크로스페이드하고 이전 트랙을 종료해. 같은 맵의 난이도·카드·특전 탭 변경이나 웨이브 시작마다 BGM을 다시 시작하지 마. 보스 종료 후에는 해당 맵의 일반/압박 곡으로 복귀해. 짧은 징글과 공격·환경 효과음은 BGM과 다른 채널로 관리해.
5. 음악 전용 음량·음소거를 기존 설정 저장 체계에 연결하되 기존 효과음 설정과 이용자 데이터를 보존해. 낮/밤, 로딩 취소, 빠른 화면 전환, 앱 복귀, 협동 양쪽 구역, 재도전에서 중복 재생·늦게 도착한 로딩 결과가 현재 곡을 덮는 문제가 없도록 구현해.
6. 무한 도전의 10단위 돌파는 J11, 100라운드는 J12를 짧게 사용하고 전투를 계속해. 100라운드를 게임 전체 엔딩으로 취급하지 마. 보상·레벨·진화 징글은 확정된 이벤트당 한 번만 재생하고 재전송·화면 재표시로 중복되지 않게 해.
7. QA 담당자처럼 PC·모바일·실제 Roblox에서 확인해. 처음/중간/끝, 세 번 이상 반복, 이음새·침묵·예상치 못한 목소리·갑자기 커지는 구간·효과음 가림을 들어 보고 수정해. 실제 실행과 청취 검증, 파일 규격 검사, 시뮬레이션을 구분해 보고해.

## 완료 조건

- 실제 업로드한 파일과 자산 ID·소유자·허용 경험이 대응한다.
- 현재 구현된 화면·맵·이벤트가 사용처표와 연결되고, 미구현 콘텐츠는 비활성 상태다.
- 단일 BGM, 전환 취소, 설정 저장, 징글 중복 방지, 보스 후 복귀가 실제 플레이에서 확인된다.
- 선택한 루프의 시작과 끝이 자연스럽고 휴대폰 스피커에서도 게임 효과음이 들린다.
- 적용 코드, 실제 ID 목록, 최종 선정 파일, 확인한 기기·조건·결과와 미검증 항목을 제출한다.

## 아직 확정하지 않은 사항

- 각 사용처의 최종 A/B·후보 1/2 선정. 원본 144개는 릴리스 첨부에서 비교할 수 있다.
- 압박곡으로 넘어갈 웨이브/위험도 기준. 제작팩은 정확한 전환 라운드를 정하지 않았다.
- 곡별 최종 음량, 징글 덕킹 비율·쿨다운, 실제 박자와 루프 이음새.
- 새 튜토리얼·챕터 엔딩·시즌·레이드·길드 이벤트의 구현 여부와 적용 시점.
