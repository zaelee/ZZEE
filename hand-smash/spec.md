# 한정선 과일찹쌀떡 × 왁뿌 3D

## 카메라 제스처 회전
한 손의 엄지·검지 집기와 이동으로 좌우 회전·위아래 기울기를 지원한다. 주먹 기반 누르기·반갈과 구분하며 회전 중 파괴 입력을 차단한다. 놓기, 추적 끊김, 손 교체 시 갑작스러운 회전·파괴를 방지한다. 기존 마우스·키보드 회전과 단면/반갈 상태를 유지한다.

사용자가 한정선을 생과일 찹쌀떡 브랜드로 명확히 정정했다. 이름표가 붙은 큐브 대신, 한정선 과일찹쌀떡의 흰 떡피·앙금·생과일 단면을 참고한 실제 3D 메시를 만든다. 겉의 왁스는 사용자가 요청한 가상 코팅으로, 실판매 제품에 왁스가 사용된다는 뜻이 아니다.

## 완료 기준
- WebGL/Three.js로 곡면 떡, 과일 단면, 광택 있는 얇은 코팅을 모델링한다.
- 누른 지점의 코팅이 갈라지고 두께 있는 곡면 파편이 떨어진다. 안쪽 떡은 남는다.
- 딸기 기본, 귤/키위 변형과 단면 미리보기, 마우스 드래그 회전을 지원한다.
- 기존 카메라 손 인식·마우스/터치·효과음·누적 점수·복원은 유지한다.
- 3D 메시 구조와 충돌을 테스트하고 실제 브라우저에서 파괴 전후와 모바일을 확인한다.
- 모델 파일(GLB)을 내려받을 수 있게 한다.

## 구조 / 제약
기존 정적 웹앱 유지. Three.js 0.180.0 한 가지 런타임 의존성을 pnpm 잠금 파일로 고정한다. MediaPipe 0.10.32는 기존 유지. 3D 모델은 코드로 직접 생성하며 참조 사진은 복제하지 않는다. 카메라 영상은 기기 안에서 처리한다. 로컬 실행 및 사용자 요청에 따라 ZZEE 인덱스와 GitHub Pages에 공개 배포한다. 실물 카메라 인식률 검증은 사용자 기기가 필요하다.

## 말랑함 / 품질 개선
- 누르고 있는 동안 눌림을 유지하고 놓으면 감쇠 스프링으로 복원한다. 빈 공간 클릭은 변형하지 않는다.
- 떡 전체의 부피를 보존하는 눌림과 접촉 부위의 국소적인 움푹함을 함께 표현한다.
- 단면 보기에서도 누르기 가능. 카메라에서 주먹을 유지하면 누름도 유지한다.
- 절차적 과육/앙금/떡가루 재질, 둥근 떡피 가장자리, 부드러운 그림자를 추가한다.
- 감소된 모션 설정, 기존 부수기·회전·GLB 저장과 모바일을 검증한다.

## 찹쌀떡 형태 / 반투명 코팅 개선
- 통째 둥근 찹쌀떡을 기본으로 표시하고, 단면 보기에서만 내부를 연다.
- 얇은 반투명 코팅을 통해 떡피가 비치도록 하며, 처음에는 균열 없는 외피로 렌더링한다.
- 크기가 다른 다각형 파편, 국소적인 금, 누적 손상, 순차 탈락, 접시 충돌을 적용한다.
- 최초 접촉과 실제 탈락을 구분하고, 지속 누르기·복원·전체 제거·내부 유지·모바일·GLB를 검증한다.

## 80% 제거 후 반갈
현재 떡의 왁스를 80% 이상 제거하면 당기기를 연다. 천천히 당기면 늘어나고 놓으면 복원하며, 충분한 거리와 빠른 바깥 방향 움직임이 함께 감지되면 반으로 가른다. 두 손의 주먹 벌리기, 한 포인터 드래그와 두 포인터 벌리기, 키보드 T/버튼 대체 입력을 지원한다. 갈라진 단면에 현재 과일을 표시하며 복원·과일 변경으로 초기화한다.

## 모바일 최적화
작은 화면에서는 떡과 네 개의 주요 조작 버튼을 우선 표시하고 상세 설정은 접어둔다. 세로·가로 모드와 안전 영역에 대응한다. 모바일 렌더링은 조작 중 최대 30fps, 대기 중 약 6fps로 제한하고 화면 밖·숨겨진 탭에서는 중지한다. 기존 터치·카메라 제스처·80% 제거 후 반갈을 유지한다. 에뮬레이션 검증과 실물 휴대폰 검증은 구분한다.

## 전체화면 카메라와 단면 제스처
카메라 모드에서 떡을 작게 표시하고 전체화면 또는 뷰포트를 채운다. 반투명 버튼으로 렌즈 전환과 종료를 제공한다. 전면은 거울상, 후면은 원본 방향으로 영상과 손 좌표를 일치시킨다. 한 주먹 또는 연속 5초 누르기로 단면을 열고 기존 두 주먹 반갈을 보존한다. 코팅 파열과 탈락에 맞춘 합성 효과음, 실제 탈락 시 짧은 진동, 개별 끄기와 미지원 환경 처리를 제공한다.
