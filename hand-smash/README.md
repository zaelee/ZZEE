# 왁뿌 — 한정선 과일찹쌀떡 3D

## 손 제스처 회전

카메라를 켜고 한 손의 엄지·검지 끝을 맞댄 채 나머지 손가락은 폅니다. 좌우 이동은 회전, 위아래 이동은 기울이기이며 두 손가락을 벌리면 놓습니다. 별도로 회전 모드를 누를 필요가 없고, 단면 보기와 반갈 후에도 사용할 수 있습니다.

집기 인식 중에는 손의 부수기·반갈 입력을 막습니다. 집기를 푼 직후 200ms도 파괴 입력을 막고, 추적 끊김·손 교체·큰 좌표 튐은 회전 기준점을 다시 잡습니다. 양손을 동시에 집으면 회전할 손을 임의로 선택하지 않습니다. 주먹은 기존 누르기·반갈 동작으로 유지합니다.

구문 검사와 단위 테스트 17개 통과. 합성 카메라 영상과 손 좌표로 실제 앱의 회전·기울기·왁스 보호·놓기·추적 손실·단면 회전·카메라 종료를 브라우저에서 확인했습니다. 실물 손의 인식률은 검증하지 않았습니다.

## 왁스 80% 제거 후 반갈

- 현재 떡의 64조각 중 52조각 이상이 떨어지면 반갈이 열립니다. 누적 점수와 별개입니다.
- 마우스/터치로 떡을 잡고 옆으로 크게, 빠르게 당기세요. 두 손가락으로 양쪽을 잡아 벌릴 수도 있습니다.
- 카메라에서는 떡 위에 두 주먹을 놓고 양옆으로 빠르게 벌립니다. 손이 사라지거나 주먹을 풀면 당기기를 취소합니다.
- 느리게 당기면 늘어나고 놓으면 복원됩니다. 짧은 움직임이나 느린 당김은 반갈을 일으키지 않습니다.
- 버튼이나 T 키로도 준비된 떡을 가를 수 있습니다. 단면 미리보기·회전 모드에서는 반갈하지 않습니다.
- 반갈 상태에서 GLB를 저장하면 두 반쪽 모델을 내보냅니다. 다시 코팅하거나 과일을 바꾸면 초기화됩니다.
- 힘 센서 대신 이동 거리와 최근 120ms의 속도로 강한 당김을 판정합니다. 단위 테스트 13개와 브라우저의 80% 경계, 느린/빠른 당김, 복원, 버튼, 모델 저장, 모바일 레이아웃을 검증했습니다. 실제 두 손 카메라 인식률은 검증하지 않았습니다.

한정선 생과일 찹쌀떡의 떡피·앙금·과일 단면을 참고한 3D 체험입니다. 실제 판매 제품을 스캔한 모델이 아닌 직접 만든 입체 모델이며, 겉의 왁스는 요청에 따라 추가한 가상 코팅입니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 실행합니다. 의존성이 이미 설치되어 있으면 첫 명령을 생략할 수 있습니다.

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm start
```

http://localhost:4173 을 여세요. 인앱 브라우저가 카메라를 지원하지 않으면 Chrome 또는 Safari에서 같은 주소를 여세요.

## 조작

- **카메라로 시작**: 카메라 권한을 허용하고 떡 위로 손끝을 움직이거나 주먹을 쥡니다.
- **카메라 없이 먼저 해보기**: 클릭/드래그/터치로 닿은 부분의 코팅을 부숩니다.
- **Space / 코팅 한 번에 벗기기**: 남은 코팅을 한 번에 부숩니다. 떡과 과일은 남습니다.
- **단면 먼저 보기**: 점수 변화 없이 왁스를 잠시 숨겨 내부를 봅니다.
- **돌려서 구경하기**: 드래그하거나 방향키로 3D 모델을 회전합니다. 부수기 버튼으로 돌아갈 수 있습니다.
- **과일 선택**: 딸기, 통귤, 골드키위 중 선택합니다.
- **다시 코팅하기**: 64개 왁스 조각을 복원합니다. 누적 점수는 유지됩니다.
- **3D 모델 저장**: GLB 파일을 저장합니다. 단면 미리보기 중 저장하면 내부 모델만 내보냅니다. 일반 보기에서는 온전한 코팅 모델을 내보냅니다.

## 모델 구조

`mochi-model.js`가 바닥이 눌린 둥근 찹쌀떡과 별도의 과일 단면, 앙금, 곡면 왁스를 생성합니다. 기본 모습은 통째 찹쌀떡이며 단면 보기에서 속을 확인합니다. 딸기 과육은 돌출 메시와 씨앗, 귤은 분리된 과육 조각, 키위는 과육과 씨앗으로 구성합니다. `wax-geometry.js`는 표면을 크기가 다른 64개의 불규칙 다각형으로 나눕니다. 왁스는 외피·내피·옆면을 가진 얇은 반투명 곡면 파편입니다. `mochi-view.js`가 WebGL 조명·표면 광택, 레이캐스팅 충돌, 파편 중력·회전과 GLB 내보내기를 담당합니다.

Three.js **0.180.0**을 추가했고 `pnpm-lock.yaml`로 고정했습니다. 실제 메시 렌더링, 표면 재질과 3D 충돌을 위해 사용합니다. 별도 서버 프레임워크나 물리 엔진은 없습니다. 파괴 연출은 미리 나뉜 코팅 메시와 단순 중력/반사 방식이며 재료의 물리 시뮬레이션은 아닙니다.

## 개인정보와 요구 환경

카메라 영상은 기기에서 처리하며 녹화·업로드하지 않습니다. MediaPipe 0.10.32 및 Google 손 인식 모델과 웹폰트는 인터넷에서 불러옵니다. WebGL, localhost 또는 HTTPS, 첫 손 인식 실행 시 인터넷이 필요합니다. 카메라 끄기/화면 이탈 시 스트림을 종료합니다.

## 말랑함과 재질 개선

- 마우스/터치로 누르는 동안 눌림을 유지하며, 카메라에서 주먹을 유지해도 같은 반응을 보입니다. 단면 보기에서도 누를 수 있습니다.
- 전체 눌림은 부피를 유지하는 스케일 변화, 접촉 부위는 정점 셰이더의 국소 변형을 사용합니다. 놓으면 감쇠 스프링으로 출렁이며 복원됩니다.
- 동작 감소 설정에서는 탄성 진동을 없애고 부드럽게 복원합니다. 빈 공간은 반응하지 않습니다.
- 떡피의 곡면 테두리와 미세 가루 질감, 과일의 색상·요철·거칠기 맵, 촉촉한 표면 광택을 추가했습니다.
- 직접 찾은 Poly Haven의 CC0 Studio Small 05 HDR 조명을 포함했습니다. 부드러운 그림자와 환경 반사를 적용합니다. 출처는 `assets/CREDITS.md`에 있습니다.
- GLB에는 중립 형태와 색상/거칠기 텍스처가 들어갑니다. 실행 중 눌림 셰이더·스프링·파편 움직임은 웹앱 기능이며 GLB 애니메이션으로 내보내지는 않습니다.
- 실물의 정밀 연체 물리나 제품 스캔을 재현한 모델은 아닙니다.

## 반투명 왁스와 자연스러운 파괴

- 둥글고 낮은 어깨, 살짝 비대칭인 윤곽, 눌린 바닥으로 찹쌀떡 형태를 다듬었습니다.
- 얇은 왁스의 빛 투과와 흡수, 미세한 표면 요철을 사용해 흰 떡피가 은은하게 비칩니다.
- 처음에는 이어진 외피를 표시하며, 접촉하면 불규칙 경계에 금이 드러납니다. 반복 접촉이나 지속 압력으로 손상이 쌓이면 짧은 지연을 두고 떨어집니다.
- 인접 조각에는 약한 손상만 전해집니다. 점수는 실제로 떨어진 조각만 셉니다. 떡 뒤쪽 왁스가 앞쪽 빈 구멍을 통해 깨지지 않도록 충돌 깊이를 비교합니다.
- 중력과 접시 충돌을 적용한 가벼운 파편 연출이며 정밀 파괴 역학 시뮬레이션은 아닙니다.
- 이 버전에서 구문 검사와 9개 단위 테스트를 실행했습니다. 실제 브라우저에서 첫 접촉의 금 생성, 반복 누르기와 지속 압력의 국소 탈락, 빈 공간 무반응, 복원, 64조각 전체 제거, 단면 보기, 과일 변경, GLB 저장과 390px 모바일 레이아웃을 확인했습니다.

## 휴대폰 / 정적 배포

- HTTPS 링크를 휴대폰 Safari 또는 Chrome에서 열고 터치로 바로 해보기를 누릅니다. 화면을 누르고 쓸어 코팅을 벗기며, 80% 이상 벗기면 빠르게 당겨 반갈합니다.
- 화면 아래의 돌리기 버튼으로 터치 회전을 전환합니다. 코팅 한 번에 벗기기는 휴대폰에서도 사용할 수 있습니다. 카메라는 전면 카메라를 우선 요청합니다.
- 작은 화면과 가로 화면에 맞춘 조작 영역, 44px 이상 주요 터치 버튼, iPhone 안전 영역을 적용합니다. 터치 기기는 픽셀 비율 1.5, 1024px 그림자, 낮은 투과 렌더 해상도를 사용합니다.
- Three.js 0.180.0의 필요한 파일과 MIT 라이선스를 vendor/three에 포함해 node_modules 없이 정적 호스팅할 수 있습니다. pnpm install 후 node vendor-three.mjs로 갱신합니다. 카메라 인식 모델은 인터넷 연결이 필요합니다.
- 실제 휴대폰 카메라·기기별 성능은 검증하지 않았습니다.
