사고멍치 / PUPSTERS SNS 주간 콘텐츠 제작 요청문
작성일: 2026-10-27
용도: 먼저 수동으로 시험할 작업 요청문. 이 파일을 저장했다고 예약 작업이나 SNS 게시가 실행되는 것은 아니다.

아래 작업을 이 인수인계 폴더를 기준으로 수행해줘. 먼저 comic/workflow-notes.txt의 최신 4컷 제작 규칙을 적용해줘. comic/manifest.json의 사용자 검토 상태를 승인으로 바꾸어 해석하지 마.

1. brand/content-plan.json의 캐릭터 설정·회차·품질 기준과 reference/line-weight-spec.json을 읽어줘. 이미 완료한 회차와 겹치지 않는 원본 아이디어 6개를 만든 뒤, 생활 개그 1편과 관계/공감 1편을 4–6컷 완성 대본으로 골라줘. 실제 제보가 없는 이야기는 창작으로 다뤄줘.

2. 여섯 이름은 시바멈, 불돔, 머스키, 미글, 무들, 모더콜리로 고정해줘. 시바멈의 흰 눈썹과 입에 문 작은 뼈, 머스키 귀끝 얼음, 미글의 작은 침방울, 무들 머리 중앙의 작은 번개 하나, 모더콜리의 양쪽 귀와 테이프 왕관을 유지해줘. 총이나 손으로 뼈 던지기를 넣지 마. 캐릭터는 작은 코·점눈·큰 머리·짧은 몸의 기존 2D 그림을 기준으로 해줘.

3. 승인된 포즈/배경 파일이 있다면 활용 가능한 것을 찾아 컷별 배치안과 사용 파일 목록을 만들어줘. 없는 포즈는 ‘필요 에셋’으로 표시해줘. 새 이미지 생성은 현재 사용 가능한 기능과 이미 승인된 비용 범위에서만 하고, 이미지 편집에는 제공된 이미지 편집 도구와 스킬을 따라줘. 유료 API·새 구독·크레딧 구매를 임의로 연결하지 마. 기존 그림을 기본 도형으로 만든 캐릭터로 대체하지 마.

4. 각 회차의 한국어 캡션, 자연스러운 영어 캡션, 컷별 대체 텍스트와 게시 제목을 작성해줘. 영어는 직역 개그보다 상황이 전달되는 표현을 사용해줘. 그림 안 대사는 별도 텍스트로 조판할 수 있게 분리해줘.

5. 대본과 에셋 승인이 이미 끝난 회차만 최종 컷으로 편집하고, 표시 크기에서 코·눈·귀·선 굵기·대사 가독성을 확인해줘. 결과 파일을 실제로 열거나 지원되는 렌더로 확인할 수 없다면 확인했다고 표현하지 마. Instagram Reels 재가공 영상은 반응 좋은 기존 회차 한 편으로 15–25초 콘티·컷 타이밍·자막을 준비해줘. 사용 가능한 로컬 편집 도구가 있으면 새 유료 서비스 없이 출력하고 재생을 검수해줘. 도구가 없으면 완성됐다고 하지 말고 준비된 소재와 남은 단계만 남겨줘.

6. 새 결과는 new-content/YYYY-MM-DD/에 script.txt, captions.txt, assets-needed.json, review.txt 및 실제 완성한 이미지/영상으로 보관해줘. 기존 승인본은 덮어쓰지 마. 준비 상태를 idea → script_review → art_review → approved → scheduled → published로 구분하되 scheduled/published는 실제 결과를 확인한 경우에만 기록해줘.

7. 인사이트/성과 파일이 제공된 경우에만 지난 회차를 비교해줘. 실제 팔로워·도달·게임 유입 수치를 추정해서 채우지 마. 소재 선호와 게임 유입은 따로 평가하고 다음 주 변경 제안은 두 개 이하로 적어줘.

8. 이 요청만으로 SNS에 업로드·공개·예약하거나 계정을 생성·연결하지 마. 댓글·좋아요·DM·팔로우를 자동으로 실행하지 마. 게시 후보를 검토 가능한 묶음으로 저장해줘. 실제 발행은 계정과 최종 결과물에 대한 별도 지시를 받은 뒤 플랫폼의 공식 기능으로 진행해줘.

완료 보고는 이번에 준비/완성한 회차, 확인한 결과, 새로 필요한 포즈나 결정만 짧게 알려줘. 예약 실행으로 전환된 뒤 의미 있는 새 결과나 실패가 없으면 반복 상태 알림은 남기지 마.

YouTube는 별도 키즈 채널이다. 이 SNS 대본을 그대로 키즈 채널에 공개하지 말고 kids-channel-plan.json의 대상·구성을 따른다.
