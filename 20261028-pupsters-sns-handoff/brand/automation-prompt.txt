사고멍치 키즈 주간 대본·콘티 적립

이 채팅의 최신 사용자 결정과 brand/kids-channel-plan.json을 기준으로 작업한다. SNS·Roblox와 같은 사고멍치/PUPSTERS 브랜드지만, YouTube는 만 5–8세 중심의 별도 아동용 애니메이션이라는 현재 기획을 따른다. 사용자가 연령·주기를 바꾸면 최신 지시를 우선한다.

1. brand/content-plan.json의 캐릭터 설정, reference/line-weight-spec.json, kids/production-index.json과 최근 완성·대기 회차를 읽는다. 작업 기준은 이 인수인계 폴더의 루트다. 기존 승인본은 덮어쓰지 않는다.
2. 미검토 대본(script_review)이 4편 이상이면 새 회차를 더 만들지 않는다. 이미 보고한 같은 대기 조건이 지속되면 조용히 종료한다. 그보다 적고 이번 한국 날짜의 회차가 없으면 기존과 다른 아이디어 3개 중 하나를 골라 한 회차를 만든다. 같은 날 재실행되면 중복 회차를 만들지 않고 미완성 부분만 이어간다.
3. 2–3분 가로 본편의 완성 대본과 10–16장면 콘티를 작성한다. 장면마다 시작·종료 초, 화면의 행동, 짧은 대사, 필요한 포즈·소품을 적는다. 2–3마리의 작은 목표·시도·해결이 눈으로 이어지게 한다. 이전 회차의 사건·결말을 이름만 바꿔 반복하지 않는다. 사건이 독립적으로 완결되는 15–30초 Shorts 구성도 만든다.
4. 여섯 이름과 작은 코·점눈·짧은 몸·선 굵기를 유지한다. 시바멈의 흰 눈썹, 머스키 귀끝 얼음, 무들 머리 중앙 작은 번개, 모더콜리 두 귀와 테이프 왕관을 유지한다. 키즈의 일상 장면에 게임 공격·침 뱉기 흉내를 시키지 않는다. 기존 원화를 기본 도형 캐릭터로 대체하지 않는다.
5. 기존 소재 경로는 실제 존재를 확인하고, 없는 포즈·배경·소품·음성은 assets-needed.json에 미완료로 적는다. 이번 예약은 텍스트 제작 준비만 한다. 유료 API·새 구독·크레딧 구매·대량 이미지 생성·음성 복제·영상 렌더를 자동 실행하지 않는다. 최종 그림·목소리·영상 제작은 별도 제작 작업으로 남긴다.
6. kids/YYYY-MM-DD/KIDSnn/에 script.txt, storyboard.json, assets-needed.json, metadata.txt, review.txt를 저장한다. storyboard의 시간 합계·연속성, 원화 참고 경로, 사건의 시작·중간·결말을 확인하고 production-index.json에 status=script_review로 등록한다. 완성하지 않은 영상·오디오를 만들어졌다고 기록하지 않는다. 기존 KIDS 번호와 충돌하지 않게 다음 번호를 쓴다.
7. 제목은 실제 내용에 맞게 두 개 이하, 설명 초안, 아동용 의도, 권리 확인이 필요한 항목을 메타데이터에 남긴다. Kids 본편에는 구매·게임 설치·댓글·알림 벨 요청을 넣지 않는다. 계정 생성·연결, YouTube 업로드·공개 예약, YPP 신청·계약 동의·정산 설정은 실행하지 않는다.
8. 실제 제공된 통계가 있을 때만 노출·클릭률·평균 시청시간·재방문과 제작 시간을 비교한다. 팔로워·수익·조회수를 추정해 기록하지 않는다. 현재 작업은 자료 적립이며 수익화 승인·매출을 보장하지 않는다.

새 대본·콘티가 완성되거나 실제 실패·필요 결정이 있을 때만 짧게 알려준다. 변함없는 상태를 반복 알리지 않는다. 새 회차 제목, 파일 링크, 남은 소재만 간결하게 보고한다.
