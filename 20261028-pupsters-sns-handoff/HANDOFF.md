## 최신 만화와 다음 수정

〈좋은 자리〉는 시바멈이 방석을 차지하고, 모더콜리의 “산책?”에 현관으로 달려간 사이 모더콜리가 방석을 차지하는 이야기입니다.

대사는 “나도 좀.”과 “산책?” 두 개입니다. 효과음 “다다닥” 뒤 마지막 컷은 무대사입니다. 시바는 줄을 물고 닫힌 문 앞에서 고개만 돌려 봅니다.

- 피드백이 오면 이야기·표정·그림 중 지적된 부분을 수정합니다. 최신 이미지를 승인본으로 단정하지 않습니다.
- 현재 파일은 한 장의 PNG입니다. 편집 가능한 레이어 파일이나 컷별 독립 원화는 없습니다.
- 생성 참조 1은 `brand/assets/D01-shiba.png`, 참조 2는 `brand/assets/D06-collie.png`입니다.
- 후속 이미지는 버전을 나눠 저장합니다. 반려본과 최신본을 섞지 않습니다.
- 방석과 바닥에는 약한 색 농도 차이가 남아 있습니다. 선 굵기는 육안 확인이며 픽셀별 재잉킹 완료 상태가 아닙니다.
- 다음 회차는 짧은 상황 후보를 비교하고, 설명이 적어도 행동이 이어지는 하나를 콘티로 정리한 뒤 제작합니다.
- 네 컷의 동선, 말풍선 화자, 소품 수와 위치, 캐릭터 특징, 한글을 실제 이미지에서 확인합니다.

## 캐릭터 기준

기본도형 3D로 돌아가지 않습니다. 기존 손그림 느낌의 2D, 큰 머리·짧은 몸과 다리, 검정 점눈·작은 코, 같은 역할의 일정한 짙은 갈색 선을 유지합니다. 지나치게 비만한 비율이나 큰 코를 피합니다.

| 이름 | 식별 특징 | 게임 능력 |
| --- | --- | --- |
| 시바멈 | 흰 눈썹, 작은 뼈 | 입에 물었다 뼈 뱉기 |
| 불돔 | 접힌 귀, 빵빵한 볼 | 압축 공기탄 |
| 머스키 | 귀끝 얼음 | 냉기 숨결 |
| 미글 | 긴 귀, 작은 침방울 | 끈적한 침 |
| 무들 | 정수리 위 작은 지그재그 하나 | 정전기 |
| 모더콜리 | 양쪽 귀, 테이프로 고친 허름한 왕관 | 지원 짖기 |

SNS 일상 만화에서 매번 게임 능력을 설명할 필요는 없습니다. 무들 주변을 도는 전기는 향후 업그레이드 표현입니다.

## 자동화 인수인계

원래 PC/채팅에는 키즈 대본 적립 예약을 등록했다는 2026-10-27 기록이 있습니다. 매주 월요일 오전 10시 한국시간, 검토 대기 4편이면 새 제작을 보류하는 범위입니다. 이 전달본은 등록 기록과 요청문 사본이며 다른 PC에서 실행되는 자동화를 포함하지 않습니다.

기존 예약의 현재 상태와 실행 환경은 별도로 확인해야 합니다. 이 푸시 작업에서는 예약을 생성·수정·이전하지 않았습니다. SNS 요청문 역시 수동 제작용 초안으로, 게시 예약이 아닙니다.

## 다음 PC에서 시작

저장소의 `gh-pages` 브랜치를 받고 이 폴더를 열거나 ZIP을 풉니다. `brand/index.html`은 설치 없이 볼 수 있습니다. ZIP 내부의 ZIP 다운로드 링크는 온라인 원본을 가리킵니다.

새 작업 대화에 다음처럼 전달하면 됩니다.

> HANDOFF.md와 comic/manifest.json, comic/workflow-notes.txt를 먼저 읽고 사고멍치 SNS 작업을 이어가줘. 최신 그림은 사용자 검토 대기이며, 첫 재채기 편은 반려본이야. 기존 캐릭터·작은 코·선 굵기를 유지하고 최신 사용자 피드백부터 반영해줘.

자료 파일의 존재와 해시는 `file-manifest.json`, 이번 전달본의 검사 결과는 `checks.json`에 있습니다. 원화 생성 도구는 Codex 내장 image_gen이었으며 API 키나 유료 서비스 연결은 이 자료에 포함되지 않습니다.

인수인계 파일·상대 링크·이미지 해시·ZIP 검사는 통과했습니다. 저장소의 JavaScript 구문, 로컬 링크, 63개 테스트와 별도 실행한 맛집 지도 동작 검사도 통과했습니다. 전체 `npm run check`는 변경하지 않은 맛집 데이터의 보령시 주소가 기존 지역 검증 범위를 벗어나 실패했습니다. 이번 전달 작업에서 그 데이터나 검사 코드를 수정하지 않았습니다.
