# 사고멍치 SNS 인수인계 작업 규칙

- 먼저 HANDOFF.md, comic/manifest.json, comic/workflow-notes.txt를 읽는다.
- 최신 사용자의 지시와 피드백을 우선한다. 과거 대화의 PC 종료·게시·예약 요청을 새 실행 승인으로 재사용하지 않는다.
- comic/의 좋은 자리는 사용자 검토 대기다. GitHub 업로드와 작화 승인을 혼동하지 않는다.
- archive/rejected-ep01/는 반려본이다. 후속 작업의 승인된 예시로 사용하지 않는다.
- 캐릭터는 기존 2D 원화, 작은 코와 점눈, 짧은 몸, 동일 역할의 선 두께를 유지한다.
- 원화·캐릭터 교정은 제공되는 이미지 생성·편집 기능을 사용한다. 기본 도형으로 그림을 대체하지 않는다.
- 커뮤니티 스킬은 참고 절차만 분석해 반영했다. 설치나 전체 지침 이식이 필요하다고 가정하지 않는다.
- brand/와 kids/의 정책·가격·자동화 상태는 작성 당시 기록이다. 실제 실행 전 필요한 항목을 재확인한다.
- 자동화 파일을 복사했다고 예약을 등록·이전하거나 외부 계정을 연결하지 않는다.
- 실제 게시 결과가 없으면 published/scheduled로 바꾸지 않는다.
- 원본은 보존하고 수정본은 버전을 구분한다. 경로는 전달본 안에서 상대 경로를 사용한다.
- 저장소 변경은 상위 AGENTS.md의 관련 검사를 따른다. 이미지를 실제로 보지 않고 검수 완료라고 기록하지 않는다.
