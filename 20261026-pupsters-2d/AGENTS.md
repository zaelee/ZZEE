# Pupsters 2D handoff

- Read HANDOFF.md, docs/art-direction.json and docs/line-weight-spec.json before editing art.
- Preserve the six canonical names, small nose, dot eyes, seated short proportions, breed signatures and body-powered attacks.
- The newest priority is consistent line weight at actual display sizes. Existing PNGs still need selective re-inking; do not claim they already meet exact stroke widths.
- Preserve separate transparent characters/enemies, background, UI, effects and live text. Do not replace the requested artwork with primitive 3D or a single flattened screen.
- Keep personal machine paths, account/cache identifiers, credentials and cookies out of published files.
- Use Node24. Run the folder's check-ui.mjs/check-flow.mjs for changes affecting UI, then follow the repository's npm run check requirement. Browser-free tests do not establish rendered or Roblox behavior.
- For raster editing, use an available image editing workflow with the existing character as reference. Keep the current design unless the user requests a change. Do not silently add paid generation services.
