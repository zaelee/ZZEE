사고멍치 / PUPSTERS — 2D 리디자인
2026-10-26

시작
압축을 풀고 index.html을 브라우저에서 여세요.
별도 설치나 계정 없이 로컬에서 화면 디자인을 살펴볼 수 있습니다.

이번 기준
굵고 조금 삐뚤한 짙은 갈색 선, 아이보리 바탕, 견종별 포인트색.
작은 검정 점눈, 머리 너비의 약 25–30%를 차지하는 검정 코.
앉은 자세, 머리가 크고 몸통과 다리가 매우 짧은 비율.
첫 시안에서 코가 크다는 피드백을 반영해 시바멈 코를 약 65%로 축소했습니다.
나머지 다섯 마리도 줄인 코를 기준으로 제작했습니다.

캐릭터와 공격
D01 시바멈: 흰 눈썹. 입에 문 작은 뼈를 뱉습니다.
D02 불돔: 접힌 귀와 빵빵한 볼. 입으로 압축 공기를 쏩니다.
D03 머스키: 얼어붙은 귀끝. 입에서 냉기를 내뿜습니다.
D04 미글: 긴 귀와 작은 침방울. 끈적한 침을 뱉습니다.
D05 무들: 곱슬털과 정수리의 작은 번개 하나. 털에서 정전기를 방출합니다.
D06 모더콜리: 양쪽 귀, 테이프로 붙인 낡은 종이 왕관. 짖어서 아군을 지원합니다.

파일 구성
assets/characters : 강아지 6마리, 개별 투명 PNG
assets/enemies    : 일반 몹 8종과 보스 1종, 개별 투명 PNG
assets/backgrounds : 길/캐릭터/UI가 합쳐지지 않은 거실 배경
assets/ui        : 버튼, 패널, 아이콘, 경로, 배치 슬롯 SVG
assets/effects   : 개별 공격 효과 SVG
previews         : 캐릭터/몹 모아보기 및 화면 미리보기
docs             : 에셋 목록, 비율 기준, 생성 프롬프트, 검사 기록

사용 범위
이 파일은 2D 그림과 클릭 가능한 UI 디자인 프로토타입입니다.
전투 수치와 진행은 디자인 확인용 데모이며 확정된 게임 밸런스가 아닙니다.
협동 화면은 화면 디자인만 포함하며 네트워크 연결 기능은 없습니다.
캐릭터 PNG는 기본 앉은 자세입니다. 데모의 변형/효과 연출은
실제 프레임별 공격 스프라이트나 Roblox 애니메이션 파일이 아닙니다.

Roblox로 옮길 때
PNG를 이미지 에셋으로 등록하고 실제 에셋 ID를 ImageLabel/ImageButton에 연결합니다.
SVG UI/효과는 원하는 표시 해상도로 PNG로 내보내서 사용합니다.
라벨 텍스트는 이미지에 합치지 않고 TextLabel로 따로 배치합니다.
기본 앉은 자세 이미지는 로비/편성/캐릭터 UI와 고정 시점의 전투 실험용입니다.
다방향 전투를 확정하면 시점/방향별 프레임, 입 위치와 발 기준점,
피격 판정과 실제 공격 로직을 별도로 맞춰야 합니다.
이 패키지에서는 Roblox Studio 연결/업로드/게임 동작 검증은 하지 않았습니다.

제작
강아지·몹·거실 그림은 Codex 내장 이미지 생성 도구로 제작했습니다.
generation-prompts.json과 enemy-prompts.json에 제작 지시를 남겼습니다.
UI 글자와 버튼은 그림과 분리해 수정할 수 있도록 작성했습니다.
이전 3D 파일과 기존 시안은 변경하지 않았습니다.

선 두께 제작 기준 (2026-10-26 피드백 반영)
previews/line-weight.html에서 96/128/256px로 크기를 맞춰 비교할 수 있습니다.
docs/line-weight-spec.json에 외곽/내부/세부선 세 단계와 공통 제작 프롬프트를 저장했습니다.
UI에서 캐릭터와 몹에 덧붙였던 검정 그림자를 제거했습니다.
UI 아이콘은 64단위 캔버스에서 외곽5, 세부3.5단위로 정리했습니다.
기존 PNG 전체의 선을 다시 그린 버전은 아니며, 원화 간 차이는 비교 페이지에 표시했습니다.
