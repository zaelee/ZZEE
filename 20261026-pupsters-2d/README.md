## 먼저 확인할 결정

최신 피드백은 **선 두께의 일관성**입니다. 외곽선·내부선·세부선의 역할을 나누고 실제 표시 크기에서 비교합니다. 기준은 [line-weight-spec.json](docs/line-weight-spec.json)에 있습니다. UI 아이콘 규격과 캐릭터 덧그림자는 정리했지만, PNG 원화 전체를 다시 그려 통일한 상태는 아닙니다.

캐릭터는 큰 머리, 매우 짧은 몸, 앉은 자세, 검정 점눈과 작은 코를 유지합니다. 시바멈의 흰 눈썹·입에 문 뼈, 머스키의 얼음 귀끝, 미글의 침방울, 무들의 작은 정수리 번개 하나, 모더콜리의 양쪽 귀와 낡은 왕관을 보존합니다. 공격은 총 없이 입·털·짖기로 표현합니다.

## 파일과 실행

압축을 풀고 `index.html`을 열면 됩니다. 화면에는 외부 라이브러리나 계정이 필요하지 않습니다.

| 위치 | 내용 |
| --- | --- |
| `assets/characters/` | 강아지 6종, 개별 투명 PNG |
| `assets/enemies/` | 일반 몹 8종과 보스 1종, 개별 투명 PNG |
| `assets/backgrounds/` | 길과 UI가 합쳐지지 않은 거실 배경 |
| `assets/ui/` | 패널·버튼·경로·슬롯·아이콘 SVG 19개 |
| `assets/effects/` | 별도 공격 효과 SVG 6개 |
| `docs/` | 제작 기준, 생성 프롬프트, 에셋 목록, 검사 결과 |
| `tools/` | 검사 및 모아보기 생성 도구 |

Node 24에서 `node tools/check-ui.mjs`와 `node tools/check-flow.mjs`를 실행합니다. 저장소 전체는 상위 폴더에서 `npm run check`로 검사합니다. 모아보기 PNG를 다시 만들 때만 Python 3, Pillow, 한글 폰트가 필요합니다.

이것은 클릭 가능한 디자인 프로토타입입니다. 실제 전투 로직·온라인 협동·Roblox Studio 연결은 포함하지 않습니다. 모션은 기본 PNG 변형과 별도 효과를 조합한 데모이며 프레임별 공격 스프라이트가 아닙니다. 실제 브라우저 화면/클릭 검증은 제작 환경의 로컬 파일 정책에 막혀 미실시했습니다.

이전 버전은 [2026-10-23 개발 키트](../20261023-pupsters-dev-kit/README.md)에 보존되어 있습니다. 이전 3D 제작 지침보다 이 작업본의 2D 결정과 선 두께 기준을 우선합니다.
