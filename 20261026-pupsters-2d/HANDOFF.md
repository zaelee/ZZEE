# 다음 PC에서 이어서 작업하기

기준일: 2026-10-26, Asia/Seoul.

## 시작

이 폴더 전체를 받거나 ZIP을 풀고 `index.html`을 여세요. 새 대화에는 이 파일과 `docs/art-direction.json`, `docs/line-weight-spec.json`을 먼저 읽게 하면 됩니다. 저장소 전체를 받았으면 작업 폴더는 `20261026-pupsters-2d/`입니다.

## 현재 확정 사항

- 이름: 사고멍치 / PUPSTERS.
- 원래 손그림 2D 컨셉트로 전환했습니다. 기본도형 3D로 돌아가지 않습니다.
- 큰 머리, 짧은 몸과 다리, 앉은 자세. 비만견처럼 과하게 넓히지 않습니다.
- 검정 점눈과 작은 코. 첫 시바멈의 코를 기존 약65%로 줄인 결과가 현재 기준입니다.
- 원화·배경·효과·UI·텍스트는 분리합니다. 한 장의 게임 화면 이미지로만 납품하지 않습니다.
- 선의 색은 짙은 갈색 `#29180f`. 손맛은 경로의 작은 흔들림으로 주고 같은 역할의 선 두께를 유지합니다.

| 캐릭터 | 특징 | 공격 |
| --- | --- | --- |
| 시바멈 | 흰 눈썹, 작은 뼈 | 입에 물었다가 뼈 뱉기 |
| 불돔 | 접힌 귀, 빵빵한 볼 | 입으로 압축 공기탄 |
| 머스키 | 얼어붙은 귀끝 | 냉기 숨결 |
| 미글 | 긴 귀, 침방울 | 끈적한 침 뱉기 |
| 무들 | 곱슬털, 정수리 작은 번개 하나 | 털에서 정전기 |
| 모더콜리 | 양쪽 귀, 테이프 붙인 낡은 왕관 | 아군을 돕는 응원 짖기 |

무들 주변을 도는 전기는 향후 업그레이드 표현입니다. 기본형에는 정수리 번개 하나만 유지합니다.

## 바로 다음에 할 일

1. `previews/line-weight.html`에서 96/128/256px로 비교합니다. 파일의 투명 여백을 제외한 실제 도형 크기를 맞춘 페이지입니다.
2. PNG 선 두께를 다듬을 때 분열 블록봇(E05), 블록사우루스(B01), 운반차(E08), 벽돌 덩치(E03)의 가늘고 많은 내부선을 우선 검토합니다. **전체 PNG의 선 통일은 아직 완료되지 않았습니다.**
3. 시바멈 원화를 공통 스타일 참조로 사용하고 `docs/line-weight-spec.json`의 `prompt_suffix`를 생성 지시에 붙입니다. 생성 수치가 정확히 보장되는 것은 아니므로 실제 축소본을 다시 비교합니다.
4. 캐릭터 형태와 작은 코를 유지하면서 선만 조절합니다. 검정 그림자를 덧대 외곽선을 두껍게 보이게 하는 방법은 사용하지 않습니다.
5. 원화가 확정되면 전투 시점/방향과 공격 준비→발사→회복 프레임을 정합니다. 현재 PNG는 앉은 기본 자세이며, 완성된 방향별 애니메이션 시트가 아닙니다.

현재 UI에서 타이틀·편성·스테이지·전투 배치·협동 로비·보스·승패·도감·에셋 킷을 살펴볼 수 있습니다. 설정은 모달입니다. 협동, 전투 수치, 승패 기록은 디자인 데모입니다.

## 제작과 검사

강아지·몹·배경은 Codex 내장 이미지 생성 도구로 제작했습니다. `docs/generation-prompts.json`과 `docs/enemy-prompts.json`에 지시가 있습니다. 다른 환경에서 도구가 없으면 원화를 그대로 검토·활용할 수 있으며, 유료 API나 계정 연결을 임의로 추가하지 않습니다.

Node 24:

```sh
node tools/check-ui.mjs
node tools/check-flow.mjs
node tools/build-line-review.mjs
node tools/package.mjs
```

`check-flow.mjs`는 브라우저 없는 이벤트/마크업 검사입니다. 실제 브라우저 클릭과 렌더 검증을 했다고 해석하지 않습니다. 이미지 원본 검사와 모아보기 재생성은 Python 3 + Pillow로 `python tools/inspect-assets.py`를 실행합니다. 필요한 경우 환경 변수 `PUPSTERS_FONT`에 한글 폰트 파일 경로를 지정합니다.

수정 후 `node tools/package.mjs`로 원화/부품 해시를 갱신하고, `python tools/build-download.py`로 다운로드 ZIP도 갱신합니다. `docs/publication-check.json`은 이 날짜 공개본의 검사 기록입니다.
