## 다음 담당자가 먼저 알아야 할 것

사용자는 가성비와 디자인을 함께 중요하게 본다. 이전 광범위한 추천의 상당수에 만족하지 않았고, 가격이 네이버·쿠팡과 다르다고 지적했다. 최종 단계에서는 재추천을 멈추고 카테고리와 크기가 있는 정확한 목록을 요청했다. 여기의 미정 후보를 사용자 선택으로 둔갑시키지 말 것. 필요 없는 재확인 질문을 반복하지 말고 이미 한 결정을 유지한다.

### 유지할 결정

1. 코팅 프라이팬: **락앤락 핸디 IH 24cm**. 한국소비자원 시험 대상 모델을 원한다. 도루코는 디자인 때문에 제외했다.
2. 코팅 웍: **락앤락 핸디 IH 28cm 웍**. 사용자가 제품이 존재한다고 직접 정정하고 추가를 요청했다. https://store.ohou.se/goods/891481 에서 제품 존재 확인. 조사 당시 해당 판매처는 일시품절. 24cm 프라이팬의 소비자원 시험 결과를 28cm 웍의 직접 시험 결과로 표현하지 않는다.
3. 라면 냄비: **하로로라는 특정 브랜드**. ‘호로/법랑’의 오타가 아니라고 명확히 답했다. 정확한 모델은 아직 고르지 않았다.
4. 냉동밥 용기: **도자기 350mL**, 밥 200g 소분용. 250mL로 되돌리거나 용량을 미정으로 만들지 않는다. 내부 형상·뚜껑 공간·냉동/전자레인지 적합 표시는 구매 제품에서 확인한다.
5. 실리콘 조리도구는 **다이소에서 살 계획**. 공식 다이소몰에서 정보를 확인하라고 요청했다. 네오플램 개별 모델은 조사 후보이지 모두 구매 확정은 아니다.
6. 칼과 생고기 가위는 손잡이까지 올스텐을 우선한다. 칼은 직접 갈기보다 교체 부담이 적은 가격대. 신뢰할 만한 YouTube 절삭력 비교를 원한다.
7. 도마는 플라스틱 제외. **세라믹 + 주력 나무 + 김치용 스텐**. 스텐은 보관이 편해야 한다.
8. 손님용 전골냄비: 2~4인 샤브샤브·스키야키·전골. 논스틱 코팅은 신경 쓰여 피하고 싶다. 디자인이 좋으면 이 품목은 돈을 조금 더 쓸 의향이 있다. ‘쿡플레이트’는 전기 조리기기로 확정한 표현이 아니다.
9. 조리용 냄비·팬·뚝배기는 **인덕션과 하이라이트 모두 대응**해야 한다.

### 도마/실리콘/밥용기

- 플라스틱 도마 제외는 사용자의 선호. 미세플라스틱 위해가 확정됐다고 과장할 필요 없음.
- 세라믹 무늬 PP 도마와 실제 도자기를 구분. 단단한 세라믹/스텐 표면의 칼날 영향 확인을 이어갈 것.
- 위생 참고 1차 자료: https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/cutting-boards
- 나무도 세척·완전 건조·날고기/바로 먹는 음식 분리를 전제로 사용한다. 나무 자체를 무조건 비위생적이라고 하지 않는다.
- 도자기 350mL는 밥 200g을 위한 선택 용량. 제품 실측을 한 것은 아니며 모든 모양의 350mL 용기에 같은 방식으로 들어간다는 뜻은 아니다.

## 다음 작업 제안

1. 사용자에게 다시 전체 추천을 쏟아내지 말고, 현재 목록을 기준으로 요청한 품목부터 좁힌다.
2. 밀폐 가능한 소형 스텐볼(흔들기용)과 24/36cm 볼·채망 실제 호환 제품 확인. 뚜껑은 단순 덮개인지 밀폐인지 반드시 구분.
3. 핸디 24 프라이팬·28 웍 구매 가능한 정확한 SKU와 열원 대응 확인. 다른 핸디/패턴/클래시 제품을 섞지 않는다.
4. 하로로 라면냄비 모델, 2L급 뚝배기, 비코팅 손님 전골냄비를 구체화한다. 일반 도자기 냄비를 인덕션 대응으로 추정하지 않는다.
5. 다이소 실리콘 제품 표시·젓가락 실사용 리뷰, 350mL 도자기 밥용기, 스텐 반찬통 라인을 찾는다.
6. 칼·가위는 올스텐/가격/유튜브 직접 테스트를 함께 만족하는지 확인. 초기 절삭력과 날 유지력, 과도와 식도 시험을 구분.
7. 안전/사용법은 공식 자료로 확인. 사진은 실제 상품 이미지로 제시하고 모델·옵션과 일치시킨다.

가격 비교는 동일 모델·크기·수량, 새 상품 기준으로 한다. 일반가/쿠폰/와우/카드/배송/품절을 분리한다. 기존 조회에서 네이버쇼핑은 보안 확인 화면에 막혔다. 다른 컴퓨터에서 정상 접근되면 직접 확인하되 CAPTCHA를 임의 우회하지 않는다. 가격을 못 확인한 경우 확인된 것처럼 말하지 않는다.

## 저장소 및 게시 방식

- 정적 HTML/CSS/JS 사이트이며 추가 의존성 없음.
- `index.html`: Information 영역의 주방 준비 카드.
- `kitchen-setup/index.html`: 목록·선택·조사 기록·이어하기 본문.
- `kitchen-setup/styles.css`: PC/모바일/인쇄 스타일.
- `kitchen-setup/app.js`: 로컬 검색/필터/이어하기 문구 복사만 담당. 사용자 선택을 localStorage에 숨겨 저장하지 않음.
- `kitchen-setup/HANDOFF.md`: 이 파일. 최신 선택과 미완료 사항을 페이지와 함께 갱신한다.
- `.mise.toml`의 Node 24 사용. 저장소 `AGENTS.md`를 먼저 읽고 `mise exec -- npm run check`를 실행한다.
- GitHub Pages는 API 조회 결과 **gh-pages 브랜치의 루트**에서 게시된다. `main`의 다른 변경 전체를 gh-pages에 덮어쓰지 않는다. 두 브랜치에 별도 프로젝트가 있어 차이가 존재한다.
- 이번 작업은 각 원격 최신 브랜치에서 분리한 작업 트리에서 주방 관련 파일과 목차 카드만 추가했다. 이전에 열려 있던 작업 브랜치는 변경하지 않았다.
- 사용자는 이번 기록의 푸시/게시를 허용했다. 이후 요청이 단순 조회라면 자동으로 다른 변경을 푸시하지 않는다.
