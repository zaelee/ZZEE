B달빛 거미 / 여우 술사月光蜘蛛 / 白狐術師대체 제어·지원거미는 둔화, 여우는 밀쳐내기·증폭 역할로 소개됨. 부족한 역할을 채우되 희귀 재화 투자는 신중하게. [3]
S물리 신화 호랑이 + 표범死侍虎 + 十環豹첫 신화 축 후보두 영웅과 합체·지원 조건을 함께 확인. 여러 공략에 물리 조합 추천이 반복되지만 무조건 승리하는 조합은 아님. [4]

A*바람 신화 나비 + 올빼미皎月蝴蝶 + 怒風雕鴞보유 육성·속성 조건바람 래디언트 추천을 이 두 영웅의 무조건 최상위 평가로 해석하지 않기. [4]
B*불 / 독 신화 조합超級小熊貓 + 黑暗蝙蝠 / 鋼鐵戰蟻 + 猛毒蜂后신규 투자 후순위자료상 뉴비가 먼저 좇을 근거가 부족함. 약하다는 확정 판정은 아니며 보유 성급·속성 보너스가 좋다면 사용. [4]
보류얼티밋 / 초월 계열공식 예: 전기 「기적의 천마」입문 목표에서 제외현재 입수·합체 비용을 확인하기 전에는 투자 계획에 넣지 않기. 최상위 희귀도와 뉴비 가성비는 별개. [1]

STARTER / 편집 추천

보유 딜러 + 부족한 제어

오늘의 기본안은 무료로 얻은 딜러 + 필요한 제어 + 작동하는 기어 연결입니다. 아래는 고정 슬롯 수를 뜻하지 않는 역할 구성 예시입니다.

보유 주력 딜러 둔화 또는 밀쳐내기 기어 충전 지원
  • 물리 후보를 보유했다면 흑대성 계열·땅속 어쌔신부터 검토. 없으면 현재 가진 주력 유지.
  • 보조 후보: 상어·토끼·거미·여우의 제어 스킬. [3]
  • 막히는 원인이 화력인지, 공격 속도인지, 적 누수인지부터 구분.
성장 재화
계열 에너지원은 실제로 오래 사용할 높은 등급 주력에 먼저. 낮은 등급에 분산하기 전 보류를 검토. [8]
기어
작동하는 동력 연결을 확보하고, 변경 전후 주력의 표시 공격 속도를 비교. [5]
카드 선택
현재 부족한 역할을 보완. 주력의 티어·핵심 스킬을 개선하는 선택지를 먼저 비교. [9]
옵션 정제
초반에는 이미 쓸 만한 옵션을 유지. 핵심 조합이 정해지기 전에 완벽한 옵션을 노리며 재화를 소모하지 않기. 편집 추천
PHYSICAL / 조건부 추천

호랑이·표범 축부터 확인

원문 합체 쌍은 死侍虎 + 十環豹입니다. 두 영웅의 보유 여부와 인게임 합체 도감 조건을 먼저 확인합니다. [4]

물리 신화 쌍 보유 물리 딜러 필요한 제어
  • 한쪽만 보유했다면 주력 덱을 유지하면서 나머지 조각·선택권을 계획.
  • 합체 전후의 화력·제어 공백까지 확인.
  • 물리 덱이 불리한 스테이지 조건이면 해당 속성 대안을 비교.
신성한 나무
중상 대상 공격의 확정 치명 효과가 실제로 작동할 때, 물리/전체 치명 피해와 피해 증가를 우선 비교하는 유저 추천이 있음. [6]
치명 확률
위 조건이 없으면 ‘물리는 치확 불필요’라는 결론을 적용하지 않기. 현재 스킬·성급·보스 적용 여부 확인.
코어
표범 코어처럼 지원 기능이 있는 코어는 상위 색깔 코어가 생겨도 효과부터 비교. [6]
