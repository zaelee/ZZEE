FUSION / 현재 도감 일치 여부 확인

실제 도감에 있는 조합부터

한국어 플레이 화면에서 확인한 합체 예시입니다. 현재 도감에 같은 조합이 있는 경우에만 적용하세요.

  • 고스트 도마뱀 + 썬더 가젤 → 플레임 가젤: 영웅 상세 화면에 합체 안내가 표시됩니다. [10]
  • 실드 맘바 + 헐크 개구리 → 감마 맘바: 합체 화면의 두 재료 영웅과 결과 이름을 대조했습니다. [9] [11]

자료의 촬영 시점은 2025년 12월과 2026년 8월입니다. 조합 예시의 나열 순서는 티어가 아닙니다.

계산 = ⌈max(0, 목표 − 완료 − 무료 횟수) ÷ 묶음 횟수⌉ × 묶음 가격. 무료 횟수는 목표 누적에 인정되는 보유 티켓만 포함하세요. 미수령 환급·확률 획득·미래 보상·스퍼트 중복 보상은 자동 계산하지 않습니다. 묶음 구매가 가능한 범위에서의 예산이며, 특정 영웅 획득을 보장하지 않습니다.

속성 이름만 보고 옵션을 정해도 되나요?

현재 영웅의 스킬·해금 성급·적 조건을 먼저 확인하세요. 속성만으로 특정 옵션이 불필요하다거나 무조건 좋다고 정할 수 없습니다.

2026년 11월 쿠폰은 어디서 확인하나요?

공식 라운지와 게임 공지를 확인하세요. 공개 안내에서 JOINPAWS가 보였지만 현재 사용 가능 여부와 서버 조건을 실제 입력 검증하지 않았습니다. 이 페이지에서는 미검증 쿠폰을 ‘지금 유효’로 나열하지 않습니다. [2]

병합과 합체는 어떻게 구분하나요?

전투 중 같은 유닛·기어를 올리는 병합과, 지정된 영웅 조합으로 만드는 합체를 구분해서 보세요. 합체는 아무 영웅 두 명을 섞는 방식이 아니라, 현재 합체 도감에 표시된 조합으로 확인해야 합니다. 필요한 계정 레벨·성급·전투 등급은 현재 합체 도감에서 확인하는 것이 우선입니다. [10] [8]
